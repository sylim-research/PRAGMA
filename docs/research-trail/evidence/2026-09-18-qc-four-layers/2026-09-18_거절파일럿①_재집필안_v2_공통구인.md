## 0. 틀 (v1과 같음, 규칙만 정정)

**구인(양방향 공통)**: 원문의 핵심 의미와 화행 목적을 보존하면서, 화자의 태도·확정성·관계적 기능을 목표 상황과 목표언어에 맞게 재현하는 능력. **구인은 공통, 인지적 진입점만 다름.**

**네 층** — Gate A 원문·장면 정합 → Gate B 내용 충실성(사실·사유·조건·약속·시간 범위·**양태**) → **Pragmatic Band 화용적 의미 재현**(태도·확정성·관계적 기능·화행 목적) → Gate C 목표어 자연성. 대역을 B·C에 흡수하지 않는다.

**규칙(v2 정정)**
- 후보마다 근거 2열(내용 / 대인적 기능). **한 후보에 두 층의 결함이 같이 있으면 「복합」이라고 쓴다** — 「내용 온전·대역만 변화」로 포장하지 않는다.
- 「내용 동일」은 요소(감사·회식·주말)가 아니라 **양태·의사결정 상태·화행 목적까지** 같아야 한다.
- 완화 표현은 「가능하다」와 「필수다」를 구별한다. 어떤 번역안이 적절하다는 판정이 더 완곡한 다른 번역안을 오답으로 만들지 않는다.
- 대역 자리를 채우려고 오답을 만들지 않는다. 근거가 약하면 비워 두거나 적절 후보로 둔다.
- 해설 3단: 원문 표현의 기능 → 번역에서 달라진 것 → 가능한 재표현. 특정 중국어 표지↔한국어 종결형의 고정 판정을 쓰지 않는다.
- 높임 등급·경어 선택은 거절 초점의 배제 축 — 「해요체라서 too_blunt」 같은 판정을 하지 않는다.

**바꾸지 않는 것**: 문항 골격·척도 코드·대역 코드 · 지시문(`prompt`, v6 공통 상수) · DCT · 한→중.

## 2. MJT1 — 동료 · 등산 (키 유지)

원문 「谢谢你约我，不过这个周末我有别的安排，爬山去不了了。」 · 번역안 「같이 가자고 해 주셔서 고마워요. 그런데 이번 주말은 다른 일정이 있어서 등산은 같이 못 갈 것 같아요.」 · very/somewhat_appropriate.

**해설(v2)**: 원문은 감사(谢谢你约我) → 사정(有别的安排) → 못 간다는 결론(去不了了)입니다. 번역안은 셋을 다 옮겼습니다. 이 장면(회사 동료·메신저)에서 「못 갈 것 같아요」는 이미 정해진 거절을 전하는 흔한 한국어 표현이라 거절의 범위를 바꾸지 않습니다. 「등산은 같이 못 가요」로 옮겨도 같은 거절입니다. 없는 사유를 더하지도, 원문의 사정을 빼지도 않았습니다.

근거 2열: 내용 보존 / 기능 — 去不了了(결론) ↔ 못 갈 것 같아요(결론 유지). 완곡 표현은 이 장면에서 *가능*한 선택이지 *필수*가 아니다.

## 3. MJT2 — 친구 · 영화 (적절, 수용됨)

원문 「谢谢你约我看电影，不过这周末我去不了。」 · 번역안 **「같이 보자고 해 줘서 고마워. 그런데 이번 주말엔 못 가.」** · very/somewhat_appropriate(기준 very).

이유 선택지(채점 없음·성찰용): r1 원문의 감사와 「이번 주말」 거절을 그대로 옮겼고, 없는 사유를 보태지 않았다 / r2 「못 가」로 끝나 통보처럼 들리니 **반드시** 「못 갈 것 같아」로 바꿔야 한다 / r3 「미안」이나 아쉬움을 **더 넣어야만** 친구에게 맞다.

**해설(v2)**: 원문 「不过这周末我去不了」는 이유도 유보도 없이 이번 주말에 못 간다고 말한 것이고, 친구 사이에서 중국어로 평범한 거절입니다. 「그런데 이번 주말엔 못 가」는 감사·시간 범위·거절을 그대로 옮겼고 한국어로도 평범합니다. 「못 갈 것 같아」로 옮겨도 됩니다 — 다만 그렇게 바꿔야만 적절해지는 것은 아닙니다.

근거 2열(v2): 내용 = 감사·这周末·去不了 보존 / 기능 = 거절 부분에 유보형 없음(원문도 없음) · 감사가 초대를 받아 주는 태도를 전함(원문과 같음).

## 4. MJT3 — 신설: 거래처 담당자 · 저녁 초대 🔴 원어민 확인

| 자리 | 내용 |
|---|---|
| 제목 | 미안하다고 했는데, 거절은 전해졌을까요? |
| 장면 | 몇 번 일을 같이 한 거래처 담당자가 메신저로 이번 금요일 저녁 식사 자리에 초대했습니다. 이미 다른 일정이 있어 갈 수 없다는 뜻을 전하려고 합니다. |
| 관계 · PDR · 매체 | 몇 번 일을 같이 한 거래처 담당자 · d distant · p equal · r mid · messenger |
| 원문(신설 — **중국인 원어민 확인**) | 谢谢您的邀请。不过这周五晚上我已经有别的安排了，恐怕参加不了，真不好意思。 |
| 번역안(결함 있음) | 초대해 주셔서 감사합니다. 그런데 이번 금요일 저녁은 이미 다른 일정이 있어서 **참석할 수 있을지 잘 모르겠습니다.** 정말 죄송합니다. |
| 결함(복합) | 「恐怕参加不了」는 완곡하지만 **못 간다는 결론**입니다(그래서 뒤에 사과가 옵니다). 「참석할 수 있을지 잘 모르겠습니다」는 **아직 결정하지 않은 말**이라 의사결정 상태와 화행 목적(거절)이 바뀝니다. 내용 층과 화용 층에 걸친 복합 결함이며, 「대역만의 결함」이 아닙니다. |
| 교정 ① 유효 | 초대해 주셔서 감사합니다. 그런데 이번 금요일 저녁은 이미 다른 일정이 있어서 참석하기 어려울 것 같습니다. 정말 죄송합니다. — 노트: 「어려울 것 같습니다」는 완곡하지만 결론이 있는 말이라 「恐怕参加不了」와 같은 일을 합니다. 감사·사정·거절·사과가 그대로입니다. |
| 교정 ② 무효(내용 온전 · 태도 변화) | 초대해 주셔서 감사합니다. 그런데 이번 금요일 저녁은 이미 다른 일정이 있어서 참석하기 어려울 것 같습니다. **진심으로 사죄드립니다.** — 노트: 이 저녁 초대 거절에서 「真不好意思」가 표한 미안함보다 「사죄드립니다」는 훨씬 무겁습니다. 보탠 것도 뺀 것도 없지만, 이 문장과 관계에서는 필요 이상으로 무거운 사과가 됐습니다. |
| 교정 ③ 무효(결함 그대로) | 초대해 주셔서 감사합니다. 그런데 이번 금요일 저녁은 이미 다른 일정이 있어서, **참석할 수 있을지는 다시 확인해 보고 말씀드리겠습니다.** 정말 죄송합니다. — 노트: 원문은 이미 못 간다고 결론을 냈는데, 이 표현은 결정을 뒤로 미룹니다. 거래처는 답을 기다리게 됩니다. |
| 해설 | 원문은 감사 → 사정(이미 다른 일정) → 「恐怕参加不了」 → 가벼운 사과입니다. 恐怕는 못 간다는 결론을 완곡하게 감싸는 말이지 결정을 미루는 말이 아닙니다. 번역안은 감사·사정·사과는 옮겼지만 결론을 「모르겠습니다」로 바꿔, 못 간다는 말이 아직 정하지 않았다는 말이 됐습니다. 완곡하게 옮기는 것과 결정을 없애는 것은 다릅니다. 「참석하기 어려울 것 같습니다」는 완곡하면서 결론이 있습니다. 사과를 「사죄」로 키우면 보탠 말은 없어도 이 자리에서는 태도가 달라집니다. |

Gate A: 거래처 담당자 간 저녁 초대 거절, 메신저, 您·真不好意思 = distant·equal에 성립.
학습자가 ①을 고르려면: ③과의 차이(결론을 냈는가, 미뤘는가)와 ②와의 차이(사과 무게)를 판단해야 한다 — 보탬·빠짐 확인만으로는 못 고른다. 이것은 이 문항의 구성이지 새 생성 규칙이 아니다. 「真不好意思=가벼움 / 사죄=잘못 인정」을 일반 대응표로 쓰지 않는다 — 이 문장·관계에서의 무게 차이로만.
장치 배분: MJT1 완곡(가능) · MJT2 완곡 없음(적절) · MJT3 결론 유무·사과 강도 · MJT4 조건 탈락 · MJT5 순서·과잉 — 문항마다 다른 현상.

## 5. MJT4 — 선배 · 독서 모임 (번역안 유지)

원문 「学长，谢谢你叫我一起参加周六的读书会。不过那天我要打工，实在去不了，下次有机会我再参加。」 · 번역안 「선배, 토요일 독서 모임에 부른 건 고마운데, 그날 알바가 있어서 못 가요. 다음에 갈게요.」

**해설(v2)**: 원문은 감사(谢谢你叫我) → 사정과 확정된 거절(那天我要打工，实在去不了) → 조건부 의향(下次有机会我再参加)입니다. 번역안에서 달라진 것: ① 「다음에 갈게요」 — 「기회가 있으면」이라는 조건이 빠져, 조건부 의향이 확정된 약속이 됐습니다. ② 「부른 건 고마운데」 — 이 문장에서는 감사가 거절을 꺼내기 위한 서두처럼 읽힐 수 있습니다. 거절 자체(못 가요)는 원문대로 확정이라 고칠 것이 아닙니다. 다음 참석이 조건부로 들리도록, 감사가 감사로 들리도록 고쳐 보세요. 아래 표현은 가능한 예시이며, 다른 방식으로도 옮길 수 있습니다.

표현 메모 · 「~기 어려울 것 같아요」 — 확정된 거절을 부드럽게 전하는 한국어 표현. 거절의 범위를 바꾸지 않는 한에서 씁니다. · 「다음에 기회 되면」 — 「下次有机会」의 조건을 살리는 표현. 「다음에 갈게요」는 이 조건이 빠집니다.

참고안 1: 선배, 토요일 독서 모임에 불러 주셔서 고마워요. 그런데 그날은 아르바이트가 있어서 정말 못 가요. 다음에 기회 되면 갈게요.
참고안 2: 선배, 토요일 독서 모임 같이 가자고 해 주셔서 감사해요. 그날 아르바이트가 있어서 못 갈 것 같아요. 다음에 기회 있으면 참석할게요.
대조문(친한 동기): 토요일 독서 모임 불러 줘서 고마워. 근데 그날 알바라 정말 못 가, 다음에 기회 되면 갈게! — 해설: 거절과 조건부 다음 참석은 그대로이고, 격만 내려갑니다.

근거 2열(v2): **내용 = 有机会 조건 탈락(Gate B)** / 기능 = 조건부 의향 → 확정 약속(화행의 크기 변화). 같은 사실이 두 층에 걸친다. 「꼭」은 원문에 一定이 없어 뺐다.

## 6. MJT5 — 상사 · 회식 (v2.1: 네 후보 모두 within)

원문 「谢谢您的邀请，但我不能参加周末的聚餐。」 — 您·邀请으로 격을 갖췄고, 但…不能은 유보 없는 거절. 제목 「네 거절, 원문과 견주면 어디에 놓일까요?」

### 먼저 밝히는 사실
이 원문은 짧고 이미 직접적이다. **내용(감사·주말 회식·못 감·양태)을 그대로 두고 화용적 실현만 바꾼 후보 가운데, 방어 가능한 대역 오답을 이번 작업에서는 만들지 못했다**(모든 표현을 검토해 불가능을 입증한 것은 아니다). 유보를 더 빼면 내용(감사)이 빠지고, 더 얹으면 원문에 없는 이동(사과·양해 요청·사유)이 들어온다. v1의 「안 갑니다」(양태 변경)·「모르겠습니다」(화행 소실), v2의 「사과·양해 요청 쌓기」(이동 추가)는 그 틈을 내용 변경으로 메운 것이라 폐기했다. 어순 뒤집기(v2 #3)는 어순만으로 배려 부족을 확정할 단서가 없어 within으로 둔다. **대역 셋을 채우려고 오답을 만들지 않는다.**

| # | 후보 | 키 | 내용 | 대인적 기능 | 노트(학습자용) |
|---|---|---|---|---|---|
| 1 | 회식에 불러 주셔서 감사합니다. 이번 주말은 참석이 좀 어려울 것 같습니다. | within | 보존 | 「좀 어려울 것 같습니다」 = 결론 있는 완곡 표현. 거절 범위 不能 그대로 | 감사와 거절은 원문 그대로입니다. 「어려울 것 같습니다」는 결론이 있는 완곡한 말이라 거절의 범위를 바꾸지 않습니다. |
| 2 | 불러 주셔서 감사합니다. 하지만 이번 주말 회식은 못 갑니다. | within | 보존 | 您·邀请의 격 = 불러 주셔서 / 但…不能의 직접성 = 하지만…못 갑니다 | 원문 화자는 격은 갖추되 유보 없이 거절했고, 이 표현은 그 말투 그대로입니다. #1처럼 더 완곡하게 옮긴 것도 적절합니다 — 둘 다 같은 거절입니다. |
| 3 | 주말 회식은 못 갑니다. 불러 주셔서 감사합니다. | within | 보존(요소·양태·격) | 순서가 원문(감사→거절)과 다르지만, 감사와 거절이 모두 전해진다. 어순만으로 배려 부족을 확정할 단서가 이 상황에 없다 | 거절을 먼저 말하고 감사로 마무리했습니다. 순서는 원문과 다르지만 감사와 거절이 둘 다 전해집니다. |
| 4 | 불러 주셔서 감사합니다. 다만 이번 주말은 참석하기가 어려울 것 같습니다. | within | 보존 | 「다만」+결론 있는 완곡 표현. #1과 같은 종류의 실현 | 「다만」과 「어려울 것 같습니다」로 부드럽게 했고, 다음 약속이나 사유를 보태지 않았습니다. |

**이 문항이 보여 주는 것**: 서로 다른 네 실현이 같은 적절 대역에 놓일 수 있다는 것 — 「더 부드러운 것이 정답」도 「원문처럼 직접적인 것만 정답」도 아니다. **이 문항으로 「세 대역을 구별하는 수행」을 확인했다고 쓰지 않는다**(논문 4장 서술 경계). 원문이 직접적일 때 대역 문항이 within으로 수렴한다는 것은 이 파일럿의 관찰 사실로 기록한다.
폐기 후보(기록): 「안 갑니다」(양태 변경) · 「참석할 수 있을지 잘 모르겠습니다」(거절 소실) · 「사과·양해 요청 쌓기」(이동 추가). 「결론 유무」는 MJT3가 맡았다.

## 7. 핵심 정리 5줄 + 단원 마무리

| # | 라벨 | 문장 |
|---|---|---|
| 1 | 감사·사정·거절, 셋 다 원문에 있다 | 「谢谢你约我 → 有别的安排 → 去不了了」의 세 부분을 다 옮겼습니다. 이 장면에서는 「못 갈 것 같아요」도 「못 가요」도 그 거절을 전합니다 — 원문을 지키면서 동료에게 쓰는 한국어 표현을 고를 수 있습니다. |
| 2 | 화자가 그렇게 말했다면 | 「不过这周末我去不了」에는 유보도 미안함도 없고, 친구 사이 평범한 거절입니다. 「그런데 이번 주말엔 못 가」가 그 말입니다. 더 부드럽게 옮길 수도 있지만, 부드럽게 바꿔야만 맞는 번역이 되는 것은 아닙니다. |
| 3 | 완곡과 미정은 다르다 | 「恐怕参加不了」는 완곡하지만 못 간다는 결론입니다. 「참석할 수 있을지 잘 모르겠습니다」는 결론을 미룬 말이라 거래처는 답을 기다리게 됩니다. 완곡하게 옮기는 것과 결정을 없애는 것은 다릅니다. |
| 4 | 조건은 약속이 아니다 | 「下次有机会我再参加」는 기회가 있으면 가겠다는 조건부 의향입니다. 「다음에 갈게요」는 조건이 빠져 약속이 됩니다. 조건·시간 범위·약속의 크기는 옮길 때 그대로 둡니다. |
| 5 | 직접적인 원문은 직접적으로 옮겨도 된다 | 「但我不能参加」는 유보 없는 거절입니다. 「못 갑니다」도 「어려울 것 같습니다」도 이 거절을 전합니다. 원문에 없는 사과·사유·약속을 보태면 화자가 하지 않은 말입니다. |

단원 마무리(`unit.closing_ko`): 「중국어 화자가 얼마나 확정적으로, 어떤 태도로 거절했는지를 먼저 읽습니다. 한국어 번역은 그 거절의 범위와 태도를 바꾸지 않으면서 한국어답게 옮기는 것이지, 화자를 더 공손한 사람으로 고치는 것이 아닙니다.」
