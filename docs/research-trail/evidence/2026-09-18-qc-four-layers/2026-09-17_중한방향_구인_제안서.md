# 중→한 방향 구인 제안서 — 「상황 적절성」에서 「원문 힘의 등가 보존」으로

> 2026-09-17 밤. 연구자가 파일럿 ① 검수에서 「이건 한국인 학부생에게 예절을 가르치는 것」이라고 지적한 데 대한 설계 답안.
> **결정 전 문서.** HIGH-RISK(학습 구인·MJT 흐름) · GPT 교차검증 대상. 코드·DB 무변경.

## 1. 문제

카탈로그의 중→한 변형은 「구인 동일(상황 P·D·R 화용 적절성), 산출 장치만 한국어」로 적혀 있다.
한→중에서 이 구인은 성립한다 — 중국어를 상황에 맞게 쓰는 것은 학습자가 못 하는 일이다.
중→한에서는 성립하지 않는다 — 한국어를 상황에 맞게 쓰는 것은 한국 학생이 모어로 이미 하는 일이다.
그래서 중→한 문항은 「상사에게 이 한국어가 충분히 공손한가」를 묻게 되고, 핵심 정리는 「동료에게는 감사와 사정 하나면 충분합니다」가 된다.
**방향이 바뀌면 구인이 같을 수 없다. 「산출 장치만 다르다」는 문구가 근본 오류다.**

## 2. 중→한이 재야 할 것

한국 학생이 중국어를 한국어로 옮길 때 *못 하는* 일은 둘이다.

| | 능력 | 예 |
|---|---|---|
| (a) | **원문의 힘 읽기** — 중국어 화자가 고른 대인적 세기를 읽는다 | 「不过这周末我去不了」는 이미 완곡한 거절 · 「我理解你的需求」는 직장 거절의 표준 완충 · 「邀请」은 친구 사이 격식 과잉 |
| (b) | **힘을 보존해 옮기기** — 그 세기를 한국어로 더 세지도 무르지도 않게 | 「去不了」→「못 가」는 세진 것, 「못 갈 것 같아」가 같은 세기 |

**구인 = 원문 화자의 대인적 힘을 한국어에서 등가로 보존하기.** 상황 적절성은 원문 화자가 이미 선택했다. 학습자는 그것을 *읽고 옮긴다*.
한국어 자연성은 구인이 아니라 **바닥 조건**(Gate C). 내용 충실성은 **선행 조건**(Gate B). 힘의 등가가 판정 축.

## 3. 문항별 설계 (골격 불변 — scale4 · scale4+이유 · fix_choice · free_correction · multi_judge · DCT)

| 문항 | 지금(한→중과 동일) | 중→한 제안 |
|---|---|---|
| 지시문(1·2) | 이 번역안은 이 상황에 얼마나 잘 맞나요? | **이 번역안은 원문 화자의 말투를 그대로 옮겼나요?** |
| 척도(1·2) | 매우 적절 / 다소 적절 / 다소 부적절 / 매우 부적절 | 코드는 유지, 라벨만: **그대로 / 거의 그대로 / 세기가 어긋남 / 힘이 바뀜**. 방향(세게/무르게)은 2번 이유 선택에서 |
| 2번 이유 선택 | 왜 부적절한가 | **어느 쪽으로 어긋났나** — 「원문보다 세졌다」「원문보다 물러졌다」「원문에 없는 것을 보탰다」 |
| 3 선택 교정 | 상황에 맞게 고친 표현 | **원문의 세기를 되찾은 표현** — 오답 둘 = 세진 것·무른 것(내용은 셋 다 보존) |
| 4 자유 교정 + 대조 | 다른 관계라면 | **같은 세기를 다른 한국어 자원으로**(어순·유보·격) — 원문의 힘은 화자가 정했으니 관계를 바꾸지 않고 실현 자원을 바꾼다 |
| 5 후보 분류 | 너무 단칼 / 알맞음 / 지나치게 장황 | 코드 유지, 라벨: **원문보다 세게 / 원문 그대로 / 원문보다 무르게·장황** |
| 핵심 정리 | 한국어 예절 규칙 | **중국어 화용 사실 + 옮기기 규칙**: 「不过…去不了는 완곡 거절 → 「못 갈 것 같아」가 같은 세기, 「못 가」는 세진다」 |
| DCT 피드백 | 상황 적절성 판정 + 참고안 | **원문 이동 대조표**(살림/빠짐/보탬) → 힘 판정(세게/그대로/무르게) → 참고안. 「공손한가」는 묻지 않는다 |

## 4. 카탈로그 변경안 (`*_zh_ko` 필드, 버전 불변)

- `operational_definition_zh_ko`: 「구인 동일」 삭제 → **「원문 화자가 선택한 대인적 힘을 한국어에서 등가로 보존하는가. 학습자는 원문의 힘을 읽고(중국어 화용) 이동 없이 옮긴다. 한국어의 상황 적절성 자체는 판정 대상이 아니다.」**
- `counter_rule_note_zh_ko`: **「더 공손한 한국어가 더 좋은 번역이 아니다.** 원문이 단칼이면 단칼로 옮긴 것이 그대로다.」
- `excluded_confounds_zh_ko`: 한국어 자연성(바닥 조건) · 격식 등급 · 상황 적절성 그 자체.
- `band_schema` 코드 유지 + **`band_labels_zh_ko`**(라벨만) 신설 — 비파괴 확장, R13 무관.

## 5. 지금 밤의 「충실성 vs 대역」 논쟁과의 관계

GPT가 지킨 「내용 충실성 ≠ 대역」은 그대로다(Gate B는 선행 조건). 중→한에서 바뀌는 건 **대역이 무엇에 상대적인가**다:
한→중 대역 = 상황에 상대적 / 중→한 대역 = **원문에 상대적**. 사과 통역에서 내가 세운 「under=누락」 등식은 *내용* 층을 대역에 섞어서 틀렸다;
힘의 등가는 내용이 보존된 뒤의 *힘* 층이라 다른 얘기다. 이 구분을 교차검증에 넣는다.

## 6. 바뀌지 않는 것

문항 골격·개수 · PDR·장면·원문 · 스키마 코드 · 한→중 방향 전부 · 연구 정위(통번역 학습이 정체성, L2 화용론은 조작화 장치 — 오히려 더 정합: 중→한이 *원문 해독의 화용*이 된다) · 향상 주장 금지.

## 7. 비용·위험

- 편성된 중→한 30슬롯(c2) 전부: 지시문·척도 라벨·이유 선택지·핵심 정리·해설·DCT 피드백 방향 재집필. 원문·장면·후보 문장은 대부분 유지.
- 코드: 라벨 표시(UI, 방향별) · 변환기 상수 분기 · DCT 피드백 프롬프트(edge, 버전업·배포). **1단계는 콘텐츠만**(코드 0), 2단계에서 피드백 프롬프트.
- AI critic: 지금은 「상황 적절성」을 심사한다 → 중→한은 「힘 등가」 심사로 프롬프트 분기 필요(2단계).
- 위험 ①: 중국어가 약한 학습자는 원문의 힘을 못 읽는다 — 그게 학습 대상이다. 해설이 원문 힘의 근거를 준다(지시문에는 안 준다).
- 위험 ②: 논문 3·4장의 「방향별 구인 동일」 서술 수정(원고 — Claude 몫 아님).
- 위험 ③: 「관계 대비」 설계 스레드의 대조(contrast) 의미가 중→한에서 바뀐다(관계 대비 → 자원 대비).

## 8. 교차검증에 물을 것

1. 「원문 힘의 등가」가 L1 목표어 방향의 화용 구인으로 방어되는가(통번역학의 기능적 등가·화용 등가 논의와 어긋나지 않는가).
2. 한→중(상황 상대)과 중→한(원문 상대)이 **한 앱 안에서 다른 대역 기준**을 쓰는 것이 연구 설계상 허용되는가 — 아니면 한→중도 원문 상대로 통일해야 하는가.
3. 척도 코드 재사용(라벨만 교체)이 측정 해석을 흐리지 않는가.
4. 중→한 핵심 정리가 「중국어 화용 사실」을 가르치는 것이 「통번역 학습 정체성」과 충돌하지 않는가.
