## 0. 부탁

나는 한국어–중국어 통번역 학습 웹앱을 만들고 그것으로 교육공학 개발연구(DDR) 박사논문을 쓰고 있다. 오늘 밤 학습 문항을 정독하다 **한 방향(중→한)의 학습 구인 자체가 잘못 잡혀 있다**는 의심이 생겼고, 그에 대한 재설계안을 만들었다. 이 재설계안이 **학문적으로 방어되는지, 그리고 내가 놓친 위험이 무엇인지** 검증해 달라.

**동의해 주기를 바라지 않는다. 틀렸으면 틀렸다고, 더 나은 대안이 있으면 그것을 말해 달라.** 자료에 없는 사실은 가정하지 말고 무엇을 더 알아야 하는지 물어 달라. 문헌을 들 때는 실재하는 것만, 확실하지 않으면 「확실하지 않다」고 하라. 지어낸 인용은 이 작업에 치명적이다.

## 1. 배경 (최소한)

- 학습자: 한국 대학 중국어 통번역 전공 학부생(중급). **모어 = 한국어.**
- 연구 정위: 「화용적 적절성 중심의 통번역 교육」. 통번역 학습이 정체성이고, L2 화용론은 그것을 조작화하는 장치다. 학습 효과(사전·사후)는 주장하지 않는다.
- 미션 = 판단 문항 5개 + 직접 산출 과제 1개. 두 방향이 있다: **한→중**(한국어 원문을 중국어로) · **중→한**(중국어 원문을 한국어로). 세 교과목 중 하나(30개 미션)가 중→한이다.
- 각 문항은 원문과 그 번역안/통역안을 보여 주고, 학습자가 번역안이 얼마나 적절한지 4점 척도로 판정한다(매우 적절 / 다소 적절 / 다소 부적절 / 매우 부적절). 마지막 문항은 후보 4개를 3개 대역(예: 거절이면 「너무 단칼 / 알맞음 / 지나치게 장황」)으로 분류한다.
- 화용 초점 카탈로그가 방향별 정의를 갖는다. **중→한 변형은 현재 이렇게 적혀 있다**(저장본 주석 그대로):
  > 「구인 동일(상황 P·D·R 화용 적절성), 산출 장치만 한국어.」
  즉 두 방향이 같은 것 — *상황에 맞는 적절성* — 을 재고, 산출 언어만 다르다고 본다.

## 2. 문제

중→한 문항은 결과적으로 한국 학생에게 **「이 한국어가 상사에게 충분히 공손한가」**를 묻는다. 그건 학습자가 모어로 이미 갖고 있는 능력이다. 실제 문항의 「핵심 정리」(문항별 교훈)는 이렇게 쓰여 있었다:
> 「동료에게는 감사와 사정 하나면 충분합니다」 「상사에게는 감사와 유보로 충분합니다」

연구자(한국어 모어, 통번역 교수)의 반응: **「이건 한국어 공부잖아. 한국인 학부생들에게 예절/매너를 가르치는 건가?」**

한→중에서는 같은 구인이 성립한다(중국어를 상황에 맞게 쓰는 것은 학습자가 못 하는 일). 중→한에서는 성립하지 않는다. **방향이 바뀌면 구인이 같을 수 없는데, 카탈로그는 「산출 장치만 다르다」고 적어 두었다.** 이것이 내 진단이다.

## 3. 제안

**중→한 구인 = 원문 화자가 선택한 대인적 힘(interpersonal force)을 한국어에서 등가로 보존하기.**
상황 적절성은 원문 화자가 이미 선택했다. 학습자가 못 하는 일은 둘이다:

- (a) **원문의 힘 읽기** — 중국어 화자가 고른 세기를 읽는다. 예: 「不过这周末我去不了」는 친구 사이의 완곡한 거절 / 「我理解你的需求」는 직장 거절의 표준 완충 / 「邀请」은 친구 사이에 격식 과잉 / 「但我不能参加」는 상사에게도 꽤 직접적인 거절.
- (b) **힘을 보존해 옮기기** — 그 세기를 한국어로 더 세지도 무르지도 않게. 예: 「去不了」→「못 가」는 세진 것, 「못 갈 것 같아」가 같은 세기.

따라서 판정 축이 바뀐다:

| | 한→중(유지) | 중→한(제안) |
|---|---|---|
| 판정 질문 | 이 중국어는 이 상황에 얼마나 잘 맞나 | 이 한국어는 **원문 화자의 세기를 그대로** 옮겼나 |
| 대역이 상대적인 것 | **상황**(P·D·R) | **원문** |
| 4점 척도 | 매우 적절 … 매우 부적절 | 코드 동일, 라벨만: 그대로 / 거의 그대로 / 세기가 어긋남 / 힘이 바뀜 (방향은 이유 선택에서: 세졌다 / 물러졌다 / 보탰다) |
| 3대역(마지막 문항) | 너무 단칼 / 알맞음 / 지나치게 장황 | 코드 동일, 라벨만: 원문보다 세게 / 원문 그대로 / 원문보다 무르게 |
| 「핵심 정리」 | 한국어 예절 규칙 | **중국어 화용 사실 + 옮기기 규칙** |
| DCT 피드백 | 상황 적절성 판정 | 원문 이동 대조(살림/빠짐/보탬) → 힘 판정 → 참고안. 「공손한가」는 묻지 않음 |
| 한국어 자연성 | — | 구인이 아니라 **바닥 조건** |
| 내용 충실성 | 선행 조건 | 선행 조건(변함없음) |

카탈로그 문구 안: `operational_definition_zh_ko` = 「원문 화자가 선택한 대인적 힘을 한국어에서 등가로 보존하는가. 학습자는 원문의 힘을 읽고 이동 없이 옮긴다. 한국어의 상황 적절성 자체는 판정 대상이 아니다.」 / 반례 지침 = 「더 공손한 한국어가 더 좋은 번역이 아니다.」

문항 골격·PDR·장면·원문·한→중 방향은 바뀌지 않는다. 바뀌는 것은 중→한의 지시문·라벨·이유 선택지·해설·핵심 정리·피드백 방향·판정 키다.

## 4. 이전 교차검증과의 관계 (당신이 알아야 할 선행 판정)

오늘 앞선 교차검증에서 다음이 확정됐다: **「원문의 사실·사유·조건·약속 등 핵심 내용의 보존은 대역 판정의 선행 조건이다. 과소/적정/과잉 대역은 핵심 내용을 유지한 상태에서 화행의 대인적 힘과 기능이 목표 상황에 어떻게 실현되었는지를 본다. 누락·추가는 대역 차이가 아니라 별도의 충실성 문제다.」** 또 「under = 누락, over = 발명」이라는 등식은 대역을 충실성으로 무너뜨린다며 기각됐다.

이번 제안은 그 판정과 충돌하는가? 내 생각: 충돌하지 않는다. 내용 충실성은 그대로 선행 조건이고, 바뀌는 것은 **대역이 「목표 상황」에 상대적인가 「원문」에 상대적인가**다. 힘의 등가는 내용이 보존된 뒤의 *힘* 층이지 내용 층이 아니다. **그러나 이 구분이 정말 서는지가 당신에게 묻는 것 중 하나다.**

## 5. 쟁점

### 쟁점 1. 「원문 힘의 등가 보존」은 L1 방향 통번역 학습의 화용 구인으로 방어되는가?
- 통번역학(기능적 등가·화용 등가 논의)과 L2 화용론(사회화용/화용언어 실패) 양쪽에서 이 구인이 서는가, 아니면 이미 다른 이름으로 있는 것인가?
- 「힘」을 원문에 상대적으로 판정한다는 것이 곧 「충실성」의 재명명 아닌가? (§4)

### 쟁점 2. 한 앱 안에서 방향별로 **다른 대역 기준**(한→중 = 상황 상대 / 중→한 = 원문 상대)을 쓰는 것이 연구 설계상 허용되는가?
- 허용된다면 논문에서 어떻게 정당화하는가(방향 = L2 산출 vs L2 해독).
- 허용되지 않는다면 대안: 한→중도 원문 상대로 통일? 그러면 한→중의 「상황 적절성」 학습(학습자가 정말 못 하는 것)이 사라진다.

### 쟁점 3. 척도·대역 **코드를 재사용하고 라벨만 바꾸는 것**이 측정 해석을 흐리지 않는가?
- 같은 코드 `very_appropriate`가 한 방향에서는 「매우 적절」, 다른 방향에서는 「그대로」를 뜻한다. 데이터 분석·논문 서술에서의 함정은?

### 쟁점 4. 중→한의 「핵심 정리」가 **중국어 화용 사실**(「不过…去不了는 완곡 거절」)을 가르치는 것이 「통번역 학습이 정체성이고 L2 화용론은 장치」라는 연구 정위와 충돌하는가?
- 내 생각: 오히려 더 정합하다 — 중→한은 *원문 해독의 화용*이 되고, 그건 통번역의 절반이다. 반박해 달라.

### 쟁점 5. 내가 못 본 위험
- 학습자가 「원문에 충실하게 단칼로 옮긴 한국어」를 정답으로 배우면, 실제 통역 현장에서 그렇게 말해도 된다고 배우는 것 아닌가? 번역학의 domestication/foreignization 논의에서 이 앱은 어느 쪽을 가르치는 것이고, 그걸 명시해야 하는가?
- 그 외 구조·측정·정당화에서 보이는 위험.

## 6. 답변 형식

1. 쟁점별로 **한 문장 결론 먼저**, 그다음 근거.
2. **내 진단이 틀린 부분** — 있으면 명시. 없으면 「없다」.
3. 근거의 출처 구분 — 확립된 논의에 기대는 부분 / 당신의 추론. 실재하는 문헌만, 불확실하면 그렇다고.
4. **권고 하나 + 그 위험 하나.**
5. 이 자료만으로 판단할 수 없는 것.

간결하게. 서론·요약·격려 없이.
