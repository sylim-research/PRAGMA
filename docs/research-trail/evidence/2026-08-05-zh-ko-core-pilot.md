### 실행 계보 보완

재개 시점의 브라우저 저장소에는 1차 실행 ID가 남아 있지 않았고, 기존 선택 셀 실행 기능은
항상 새 실행 ID를 발급했다. 이 상태로 실행하면 한 파일럿의 1·2차 호출이 서로 다른 run으로
갈라진다. 따라서 관리자 화면에 다음 최소 기능을 추가한 뒤 재개했다.

- 현재 방향과 형식이 일치하는 기존 코어 실행 ID만 불러온다.
- 선택 셀을 현재 ID로 재개하거나 새 ID로 생성하는 동작을 분리한다.
- 현재 ID 재개 시 기존 저장 item을 읽어 중복 호출을 건너뛴다.
- 선택한 계획 셀의 원래 0-based item index를 유지해 `generation_item_key` 계보를 보존한다.

관련 구현은 `src/lib/pragma/coreRunIdentity.ts`,
