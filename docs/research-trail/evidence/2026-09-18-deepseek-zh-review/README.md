# 별도 AI 모델(DeepSeek)을 활용한 중국어 표현 자연성 검토 — 수행 이력 (2026-09-18)

## 위치와 위상
- PRAGMA 웹앱의 자동 품질검수 파이프라인(규칙 검사 → AI 품질 검토 → 근거 기록 → 교수자 최종 승인)의 **단계가 아니다.** v6 콘텐츠 개발·수정 과정에서 **웹앱 밖에서 추가로 수행한** 중국어 표현 자연성 검토 절차다.
- 원어민 검수가 아니다(AI 검토). 「원어민 검수」「원어민 어감 판정」「자동 검수」로 부르지 않는다.
- 호출은 연구자가 DeepSeek 웹 채팅에 검토 문서를 제출하는 방식으로 했다. API 연동은 하지 않았다(학위 범위 제외 — 호출 자동화는 기술적으로 가능함을 확인했으나, 외부 유료 의존·추가 구현·검증 부담 대비 이익이 없고 연구 기여가 아니다).
- 보낸 것은 학습 콘텐츠 문장뿐이다. 학생 개인정보는 보내지 않았다.

## 절차
1. 새로 생성·수정된 중국어 표현만 추출한다(승계 문자열은 이미 검토한 경우 제외).
2. 문장마다 **「자연스러워야 하는 표현」 / 「의도적으로 부적절하게 설계된 표현」**을 표시해 상황(한국어)과 함께 제시한다.
3. DeepSeek은 A(자연)·B(어색)·C(부자연)로 판정하고, 의도된 결함 문장은 결함과 무관한 문제만 보고하도록 요청한다(v3부터: 의도된 결함이 원어민 감각에서 실제로 결함으로 드러나는지 「flaw not clear」도 묻는다).
4. **지적을 자동 반영하지 않는다.** 연구자가 항목마다 수용/기각을 판단한다. 기준: 의도된 결함 자체에 대한 지적은 기각, 의미 보존이나 문항 의도를 훼손하는 제안은 기각, 그 외 표현 문제는 수용.
5. 수용한 경우 수정 콘텐츠를 새 버전으로 만들어 **규칙 검사와 기존 AI 품질 검토에 다시 투입**한다.

## 집계 기준
- **검토 1회 = 검토 문서 1건을 DeepSeek에 제출해 회신 1건을 받은 것.** 같은 대화 안의 추가 질문은 따로 세지 않는다.
- 지적 건수 = 회신에서 B 또는 C로 보고된 문장 수(A는 보고하지 않도록 요청함). 「flaw not clear」는 따로 적는다.
- **회차마다 대상 문장이 다르다**(전수 검토 → 신규 문장 → 재집필 후 전체 → 변경분만). 회차 간 건수 변화를 추세나 효과로 해석하지 않는다. 개발 반복 기록이다.
