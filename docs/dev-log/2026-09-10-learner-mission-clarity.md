# 학습 미션 안내·피드백 표시 정리 · 2026-09-10

- 작업: `.worktrees/admin-takeover-2026-09-10`, `codex/learner-mission-clarity-2026-09-10`, 시작 main `7bd29ca5`.
  깨끗한 기존 작업트리에서 새 로컬 브랜치로 진행했다. 복구용 기본 루트는 수정하지 않았다.
- 사용자: 앞선 판정을 수용하고 FABLE 의견의 추가점을 선별하도록 지시했다. 불필요한 검증 최소화.
  이 변경의 배포는 별도로 요청하지 않았다. 표시 수정은 단독 진행 적합, 콘텐츠 소급 변경은 미실행이다.

## 판정과 변경

- FABLE의 기존 계약 준수 점검·라벨 표시는 수용. 기존 세 번째 카드에 연결 설명이 있으므로
  '연결 문장이 없다'는 진단은 기각했다. 공통 Anchor A 때문에 '다섯 장면' 안내도 기각했다.
- 세 장 도입을 한 화면으로 압축하고 판단 5문항 → 새 상황에서 직접 통번역 → 피드백 검토와
  최종 결정 순서를 먼저 제시했다. DCT 우회 차단·DEV 별칭·이의 제기·저장 계약은 유지했다.
- 상대·전달 방식은 라벨과 값으로 표시해 `입니다.입니다` 조립을 제거했다. PDR 단서는
  상대적 지위·친숙도·부담으로 풀어 쓰며 저장값의 사실을 임의로 보충하지 않는다.
- 독립 판단의 '앞 장면과 비교' 문구를 제거했다. BEST/WORST 버튼·안내는 한글로 바꾸되
  내부 값과 구형 순위형 문항 해석은 유지했다. 번역 입력은 접근 가능한 지시 label 한 번으로 정리했다.
- 우선 피드백은 각 행동 화면에 한 번 표시한다. 긴 설명은 두 문장과 나머지 펼쳐보기로 나누고
  원 진단은 응답에 보존한다. 새 피드백 프롬프트는 1~2문장·140자 이내, 누락과 변경/추가 구분을 요구한다.
- 완료 화면은 최초안·내가 확정한 최종안·기억할 한 가지를 전면에 둔다. 최초안 AI 피드백·참고 표현·
  학급 응답은 펼쳐보기다. AI 설명을 학습자의 수정 이유로, 문자 변경을 질적 개선으로 표시하지 않는다.
- R30 warning을 코어뿐 아니라 각 MJT·DCT 상황문으로 확장했다. 단어 금지·자동 삭제·자동 탈락이
  아니며, 사전 동의 여부와 실제 도움·배려를 설명하는 사실은 보존한다.

## 실제 자료와 미적용 수정안

- 현재 교과목을 읽기 전용으로 조회한 결과 20미션·120개 상황문이다. FABLE의 11개를 재사용하지 않았다.
- 자동 신호는 DCT 3개. 별도 육안 확인에서 제안 미션 MJT 5개의 작성 방향 지시를 확인했다.
  따라서 키워드 규칙 하나로 충분하다는 처방도 기각한다. 나머지 콘텐츠의 품질 통과를 선언하지 않는다.
- `docs/research-trail/evidence/2026-09-10-scene-proposals.json`: 3미션의 DCT 3개·MJT 5개 수정 전후.
  원문·PDR·후보·정답과 MJT2~4 공통 장면을 보존한다. DCT 상황·관계는 코어와 동기화할 제안이다.
- DB·승인·기존 학습 기록은 변경하지 않았다. 실제 적용 전 현재 저장값/updated_at 대조와 기존
  콘텐츠 수정·재검수 경로가 필요하다. UI 수정만으로 저장된 문장 자체가 고쳐지는 것은 아니다.
