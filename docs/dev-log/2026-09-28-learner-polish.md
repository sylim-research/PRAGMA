# 2026-09-28 학습자 화면 다듬기 (배포 후 후속)

- 여러 표현 비교: 고른 칸을 꽉 찬 네이비 대신 네이비 테두리·옅은 바탕으로 — 하단 버튼과 겹쳐 보이지 않게.
- 피드백 결정: 「수정하기 / 이대로 확정」이 피드백 카드와 같은 폭을 반반으로 채운다.
- 완료 화면: 「미션 완료」 표지를 빼고 「내 번역, 완성!」 하나만. 취소선은 연하고 가늘게, 형광펜은 글자 아래 가는 띠로.
- 해설 꼬리표(💡 해설)를 본문 첫 줄과 같은 기준선에 맞췄다.
- 「다른 맥락에서는?」을 문항 아래 작은 곁가지로 줄여 본 문항이 주인공으로 남게 했다.
- 진행 막대·핵심 정리·기록의 활동 이름을 짧게: 표현 판단 / 판단과 이유 / 표현 비교 / 수정안 고르기 / 직접 고치기. 미션 안내의 풀어 쓴 활동명은 그대로.
- 중국어 웹 글꼴: 연구자가 명조(Noto Serif SC 500)·고딕 500·고딕 400을 나란히 비교한 뒤 **Noto Sans SC 400**으로 결정. 논문 HWPX의 중국어 예문은 명조를 유지한다.
- 검증: typecheck, build, 관련 테스트(학습자·데모·관리자 23파일) 통과, 노트북 화면(1366×768) 브라우저 측정.
- 논문 영향: 4장 학습자 화면 캡처는 이 배포 뒤 다시 채취한다.
