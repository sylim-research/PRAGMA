# 2026-09-28 학습자 화면 다듬기 (배포 후 후속)

- 여러 표현 비교: 고른 칸을 꽉 찬 네이비 대신 네이비 테두리·옅은 바탕으로 — 하단 버튼과 겹쳐 보이지 않게.
- 피드백 결정: 「수정하기 / 이대로 확정」이 피드백 카드와 같은 폭을 반반으로 채운다.
- 완료 화면: 「미션 완료」 표지를 빼고 「내 번역, 완성!」 하나만. 취소선은 연하고 가늘게, 형광펜은 글자 아래 가는 띠로.
- 해설 꼬리표(💡 해설)를 본문 첫 줄과 같은 기준선에 맞췄다.
- 「다른 맥락에서는?」을 문항 아래 작은 곁가지로 줄여 본 문항이 주인공으로 남게 했다.
- 진행 막대·핵심 정리·기록의 활동 이름을 짧게: 표현 판단 / 판단과 이유 / 표현 비교 / 수정안 고르기 / 직접 고치기. 미션 안내의 풀어 쓴 활동명은 그대로.
- 중국어 웹 글꼴: 연구자가 명조(Noto Serif SC 500)·고딕 500·고딕 400을 나란히 비교한 뒤 **Noto Sans SC 400**으로 결정. 논문 HWPX의 중국어 예문은 명조를 유지한다.
- 검증: typecheck, build, 관련 테스트(학습자·데모·관리자 23파일) 통과, 노트북 화면(1366×768) 브라우저 측정.
- 논문 영향: 4장 학습자 화면 캡처는 이 배포 뒤 다시 채취한다.

## 후속 수정 (같은 날)

- 완성 기록: 고친 곳의 빨간 취소선·노란 강조를 없앴다. 최초·최종 번역 모두 학습자가 쓴 것이라, 어느 쪽을 틀렸다고 표시하지 않는다.
- 완성 기록의 줄 이름: 언어 배지(KO/ZH) 대신 `한국어 원문`·`처음 쓴 번역`·`고친 번역`(통역이면 `통역`). 세 줄은 같은 굵기다 — 고친 번역도 틀렸을 수 있으므로 `최종`처럼 정답을 풍기는 이름과 강조를 피했다. 고치지 않았으면 `내 번역` 한 줄만 보인다.
- 피드백 판정 띠: 세 기준이 모두 좋음일 때 나오던 축하 문구를 없앴다.
- 미션 안내·진행 막대의 꼬리표를 `실제 미션`에서 `학습 미션`으로 바꿨다.
- 직접 고치기(MJT) 참고 표현: 간격을 줄이고 `예시 1`·`예시 2` 꼬리표를 붙여 여러 가능한 답 중 둘을 보여 준다는 뜻을 드러냈다. 다른 맥락 DM 말풍선은 흰 글자가 읽히도록 더 진한 파랑(#0B63CE)으로 바꿨다.
- MJT 상자 일관성 정리: 원문 줄 여백 하나(표현 비교만 넓던 것 제거), 해설 상자는 모든 문항이 「💡 해설」 한 모양, 「가능한 수정 예시」·「참고 표현」은 같은 예시 번호 상자, 선택한 보기 표시는 한 가지(남색 테두리+미색), 중국어 문장은 16.5px로 통일.
- 표현 비교(MJT) 판단 버튼 높이를 48px에서 다른 판단 보기와 같은 42px로 맞췄다. 참고 답안 상자의 「정답은 하나가 아닙니다」 안내 줄은 직접 고치기·완성 화면 모두 뺐다.
