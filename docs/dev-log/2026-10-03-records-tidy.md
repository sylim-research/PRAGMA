# 2026-10-03 학습 수행 기록 화면 정리

대상: `/admin/decision-traces` 개별 수행 기록. 보이는 방식만 정리했다(데이터·필터 기능·열 구성은 그대로).

- 기록 상세: ①②③ 번호 원과 세로 연결선, 바깥 상자를 없애고 얇은 구분선 + 소제목으로 바꿨다. 원문을 맨 위에 넓게 두고 관계·상황은 그 아래 작은 글씨로, 번역·통역 방향은 소제목 옆에 둔다. AI 피드백 칸의 미색 바탕을 옅게 해 학습자 응답(남색 테두리)만 강조되게 했다.
- 필터 줄: 선택 상자 위의 제목을 상자 안 첫 항목(「학습자 전체」 등)으로 옮기고, 「관리자 테스트 기록 포함」 상자를 테두리 없는 「테스트 기록 포함」 체크로 오른쪽 끝에 둔다.
- 표: 학습자 이름 줄바꿈 방지, 「내용」 열 머리는 화면에서 숨김(읽기 보조용으로는 남김).

## 후속 (같은 날)

- **기본 화면**: 「학습 수행 기록」은 학급 응답 분포 탭·데모 응답으로 열린다(실제 응답은 `?demo=0`). 탭 순서 = 학급 응답 분포 → 학습자별 기록. 「개별 수행 기록」 → 「학습자별 기록」. 학습자 관리의 「수행 기록 →」(`?q=`)는 계속 학습자별 기록으로 연다.
- **학습자별 기록 간소화**: 표의 화행·수행 방식 열을 미션 칸 아래 한 줄로 합치고 날짜만 남김. 주차·완료 여부 필터 제거. 상세에서 미션 내용(관계·상황)과 버전·해시 줄을 빼고, 원문은 통번역 과제 위에 한 줄로.
- **학급 응답 분포 정리**: 교과목·주차(칩 10개 → 드롭다운)·미션을 한 줄로, 실제/데모·새로고침·크게 보기·학습 미션 열기는 오른쪽 작은 글자 버튼으로. 제목은 미션 이름 한 번만, 「선택한 미션」 요약 상자와 주황 데모 안내문(배지 툴팁으로 이동)·「응답 있는 문항」 수를 제거. MJT 카드(색 막대 포함)를 얇은 탭으로 바꿔 검은 강조를 지금 보는 문항 하나에만 둔다. 집계·토론 보드 내용과 데모 데이터는 그대로.
