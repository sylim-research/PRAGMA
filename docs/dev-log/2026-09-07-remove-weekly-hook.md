# 수업자료의 별도 hook 제거 · 2026-09-07

## 사용자 결정과 원인

- 사용자는 고정 도입 예문의 품질과 실제 미션의 3단 장면 도입과의 중복을 이유로
  수업자료의 별도 hook 제거를 요청했다. [단독 진행 적합]: 범위가 확정된 기능 제거다.
- 앞선 링크 수정은 도입을 삭제하지 않았다. 검수 상세로 스크롤하면서 위의 도입 카드가
  지나쳐졌으며, 운영 2주차에서 기존 도입 화면이 열리는 것을 확인했다.

## 변경

- 별도 도입 카드·모달·스타일·고정 예문 생성기와 전용 테스트를 삭제했다.
- 수업자료 안내 문구를 정리하고 새 자료 및 서버 검수 원본에서 opening을 제외했다.
  content-review의 공유 도메인 번들을 재생성했다.
- 실제 미션의 장면 도입과 MJT5+DCT1, 유인물·교수자 메모·프로젝터는 유지한다.
- 과거 검수 행을 변경하지 않는다. opening이 포함됐던 검수 원본과 새 자료의 해시가
  달라지므로 기존 현재 버전 검수·확정 절차가 적용된다. 교수자 승인을 자동 승계하지 않는다.

## 검증과 배포

- 수업자료 UI·검수 원본 기존 회귀 검사 30개와 typecheck 통과.
- 제거된 기능의 전용 검사는 삭제하고, 기존 검사에 UI 부재·새 검수 원본의 opening 부재와
  과거 원본과의 해시 차이를 확인하는 항목을 반영했다.
- 전체 테스트·production build는 PR 필수 CI에서 실행한다.
- main 병합·CI·Railway 및 content-review 배포 결과는 연결 PR의 완료 기록에 남긴다.

## 연구 기록

- 관리자 구조 정본 §9.3.1 및 DEC-20260907-01 갱신.
- 기능 중복과 사용자 품질 판단에 따른 제거이며, 학습효과 검증 결과로 해석하지 않는다.
- 실제 미션 생성·평가 프롬프트와 DB schema 변경 없음.
