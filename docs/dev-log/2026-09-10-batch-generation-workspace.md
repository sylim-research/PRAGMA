# AI 콘텐츠 제작 자동화 유지와 배치 작업 화면 완성

- 사용자 보정: 지도교수 방침이 AI 콘텐츠 제작 자동화이므로 배치 생성 기능을 경량화하지 말고
  화면을 완성도 있게 만들라고 요청했다. 수업 편성의 규칙 기반 자동 채우기와 AI 콘텐츠 생성을 구별한다.
- 분류: `[단독 진행 적합]`. main `e7d3794e`에서
  `codex/batch-generation-workspace-2026-09-10` 브랜치로 시작했다.

## 변경

- 생성 조건, 생성 계획·분포, 실행·재개 패널을 한 흐름으로 연결했다. 실행 패널은 넓은 화면에서
  계획 옆에 두고 자체 스크롤을 지원한다. 모바일에는 실행 영역으로 가는 링크가 있다.
- 화행당 번역 입력, 수준별 번역·통역 합계와 총량을 표시했다. 통역 배율은 전체 비중이 아님을 설명한다.
- 기본 72건, 495건 본배치, 중→한 30건 검증, 모든 분포, 전체·선택 생성, 기존 ID 재개·새 ID 생성,
  생성 중단과 AI 비평 기능을 유지했다. 과거 495 계획과 별도 최종 corpus 수량을 이번 작업에서 재설계하지 않았다.
- 항목 목록에서 장면 시드를 확인하고 페이지를 넘기며 선택할 수 있다. 선택은 원래 계획 번호로 실행기에 전달한다.
- 실행 준비 시점부터 중복 요청을 막고, 조회·생성·비평 오류 뒤 제어 상태를 복구한다.
  조건 변경 때 이전 결과와 선택을 초기화해 다른 계획의 결과가 섞여 보이지 않게 했다.
- 저장·재사용·경고·실패 집계, 실패 항목 선택, 재료 라이브러리·미션 조립 연결을 제공한다.
- 생성 계획 함수, 모델·프롬프트·계약·DB·실제 생성기 및 교수자 승인 조건은 수정하지 않았다.

## 후속 · 자유 수량 제작과 교과목 유형 구분

- 사용자 확정: 교과목은 번역·통번역 반반·통역, 자동 생성은 시나리오의 절대 수량·비율 설정이다.
  재료 비율만 줄이고 모든 과목을 1+1로 유지하자는 초기 제안은 사용자 보정으로 기각했다.
  기존 과목별 저장 유형·미션 배정을 임의로 바꾸지 않고, 기존 세 유형의 편성 로직을 재사용한다.
- 72건 버튼과 고정 초기 수량을 제거했다. 수준별 총 생성 건수와 전체 중 통역 비율(0~100%)을
  직접 입력하고, `통역 = round(총량 × 비율)`, `번역 = 총량 - 통역`으로 계산한다.
  수준명과 총량을 가까이 붙여 강조하고 실제 과업별 건수를 표시한다. 빈 화면은 0건으로 시작한다.
- 배치 계획기는 모드별 절대 수량을 받아 화행에 가능한 균등하게 나눈다. 과거 화행당 quota
  호출의 수량 계산은 유지하지만, 현재 제작 화면은 이 값과 최소 통역 1건 강제를 사용하지 않는다.
  제외한 과업은 전달 분포의 대상에서 뺀다. 임의 정수 총량·비율에 도메인 1:1:1을 강제하지 않으며
  실제 분포를 사전 표시한다. 이 설정은 교과목 유형을 저장하거나 주차를 변경하지 않는다.
- 여행·이동을 공용 theme 목록·도메인 매핑·학습자 주제 표시에서 제거했다. 관련 3개 시드는
  `scenarioTopicsLegacy.ts`의 기존 저장 자료 검사 전용 목록으로 옮겨 신규 제작에서 제외했다.
  기존 자료의 R1c 검사를 깨거나 원본을 다른 테마로 재분류하지 않는다. 운영 DB 쓰기는 없다.
- 표 헤더를 한 줄로 유지하고 열 너비를 조정했다. 과목 프리셋의 과거 전반부 번역·후반부 통역
  설명을 현재 1+1 구성으로 바로잡고, 공용 유형 표시는 번역·통번역 반반·통역 순서로 맞췄다.
- 검증: 관련 5파일 61 tests 통과. 새 절대 수량·0/100%·정수 반올림·실행기 전달과 여행 테마 제외,
