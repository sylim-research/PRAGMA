# 언어별 디자인 음성과 크레딧 사전 알림 · 2026-09-07

## 결정·범위

- 사용자가 한국어·중국어 Voice Design ID를 제공하고 실제 전환을 요청했다.
  한국어 여성 1개·중국어 남성 1개로 고정하며 인물별 배정·선택 UI·성별 스키마·캐시는 추가하지 않는다.
- 이전 단일 음성 설정 및 장애 시 대체 금지는 이번 명시적 결정으로 대체한다(DEC-20260907-03).
- [단독 진행 적합]: 기존 TTS 제공자 연결의 국소 변경이다. DB·RLS·학습설계·생성계약을 변경하지 않는다.
- 키는 연구자가 Supabase secret에 직접 등록 완료했다고 알렸다. 앱·스크립트·기록에는 키 값을 넣지 않는다.

## 구현

- 서버·클라이언트가 하나의 언어별 음성 표를 공유한다. 구형 브라우저가 보낸 다른 voiceId와
  예전 sessionStorage의 disabled-voices로 언어별 지정을 우회하지 않는다.
- ElevenLabs multilingual v2: stability 0.5, similarity_boost 0.75, style 0.1,
  speaker boost true, 속도 ko 1.0 / zh 0.85.
- 키 부재·요청 실패·네트워크 장애 시 OpenAI gpt-4o-mini-tts의 같은 언어 음성을 사용한다.
  언어별 대화체 instructions와 속도를 지정한다. 400/404 호환 오류에만 tts-1-hd를 한 번 재시도한다.
  다른 언어의 디자인 목소리로 대체하거나 일시 실패한 음성을 세션 전체에서 제외하지 않는다.
- 실제 제공자·모델·voiceId·대체 여부를 응답 헤더로 반환한다. 원문 내용은 진단 로그에서 제거했다.
- tts?action=usage는 기존 관리자 인증·is_admin 검사 뒤 구독 등급·사용량·한도·갱신일만 조회한다.
  학습자·익명 사용자에게 구독 정보를 공개하지 않으며 결제 변경을 수행하지 않는다.
- scripts/check-tts-credits.mjs는 기존 PRAGMA 관리자 로그인으로 조회한다. ElevenLabs 키를 읽지 않는다.
  50% 이하 사전 경고·20% 이하 긴급 경고, 같은 주기의 6시간~7일 실제 관측에 기초한 7일 내
  소진 예상 경고를 제공한다. 초기·갱신 주기 변경·순간적인 smoke 표본에서는 소비 속도를 만들지 않는다.

## 검증·배포

- 표적 검사 14개 통과: 제공자 경로 8, 사전 경고 3, 클라이언트 일시 실패 복구 1, 통역 콘솔 2.
- typecheck 통과. 전체 테스트·운영용 build는 PR 필수 CI에서 실행한다.
- 초기 검사에서 strict:false 타입 좁히기와 jsdom 20의 AbortSignal.timeout 미지원이 드러났다.
  타입 판별을 명시적으로 고치고 네트워크 모의 검사의 timeout 경계만 대체했다.
- feature commit → main 포함 → CI → Railway SHA → tts 함수 배포와 실제 음성 응답·잔량 결과는 PR에 기록한다.
- 합성 음성 응답 확인과 실제 사람의 마이크→전사→제출→피드백→완료행 확인은 서로 다른 증거다.
  모의 통역 콘솔 검사를 실제 학습자 종단 수행으로 보고하지 않는다.

## 사전 알림·한계

- Codex 작업에 오전 9시·오후 9시 잔량 점검을 연결한다. 상태가 정상이고 변화가 없으면 알리지 않는다.
  새 경고·긴급 악화·모니터 접근 실패 시에만 알린다. 사용자 결제는 자동 수행하지 않는다.
- 로컬 예약 실행은 호스트 가용성에 의존한다. 급격한 수업 사용 증가를 항상 예측하는 보장은 없다.
  수업 전 원문 글자 수 × 미션 수 × 인원 × 재생 횟수와 잔량을 비교한다.
- 출처: ElevenLabs subscription API·voice speed 문서, OpenAI speech API.
  Free의 실제 두 voice 접근 가능 여부 및 합성 품질은 운영 응답과 사용자 청취로 구분해 확인한다.
- 연구 기록: DEC-20260907-03 및 학습자 구조 정본. 생성 프롬프트·MJT5+DCT1 계약 변경 없음.
