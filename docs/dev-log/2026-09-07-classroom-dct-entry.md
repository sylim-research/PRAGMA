# 수업용 통역 DCT 진입과 MJT 문항 정리 · 2026-09-07

## 결정과 구현

- [독립 검토 권고] 사용자 수업 운영 피드백에 따라 정규 `MJT5+DCT1` 흐름은 유지하면서 통역 카드에
  `통역 DCT 바로가기`를 추가했다. 바로가기 세션은 `entry_mode=dct_shortcut`으로 구분하고 건너뛴
  MJT 응답을 빈 배열로 저장한다.
- MJT4 Reason은 정답 방향이 항상 부적절로 고정된 적절성 판단을 제거하고 세 원인 중 핵심 이유를
  바로 고르게 했다. 문항 수와 생성 데이터의 세 이유 진단 계약은 유지한다.
- MJT5는 내부 역할과 일치하도록 화면의 `조정 필요` 계열 문구를 `BEST · 가장 적절`과
  `WORST · 가장 덜 적절`로 바꿨다. 후보 수·역할·정답 데이터는 바꾸지 않았다.
- TTS 속도는 한국어 0.85, 중국어 초·중급 0.70, 중국어 고급 0.80으로 설정했다. 현재 미션의
  학습자 수준을 클라이언트에서 Edge 함수까지 전달하며 기존 요청은 중급으로 처리한다.

## 검증

- 변경 범위 집중 테스트 28개, typecheck, production build가 통과했다. 전체 테스트는 PR 필수 CI에서 확인한다.
- 실제 운영 음성 속도와 수업용 바로가기의 운영 배포 후 청취·화면 확인은 별도 smoke로 남긴다.

## 경계

- 바로가기는 교강사가 수업시간에 DCT만 지시하는 운영 경로다. 정규 개별 수행의 완전한
  `MJT5+DCT1` 설계를 축소하지 않는다.
- 음성 속도 변경은 청취 편의 조정이며 수준별 듣기 난이도나 학습효과를 검증했다는 주장이 아니다.
