# 2026-09-16 — 기준 화면 polish 및 LOCK (진입 화면 · 학습 미션 실행)

논문 초안에 들어갈 기준 화면을 최소 변경으로 정리하고 연구자 승인 뒤 LOCK했다.
적용 원칙은 4가지로 제한했다 — 같은 위계는 같은 크기, 좌우·세로 리듬 정렬,
표면 기하 정리, 「제목 + 짧은 설명」. 색 체계·폰트·정보구조·기능은 건드리지 않았다.

## 진입 화면 `/` (LOCK)
- 보조 이동 두 개(통합 구조 보기 · 대표 미션 살펴보기)를 역할 카드보다 한 단계 아래로:
  테두리 1.5px 진남색 → 1px `#C4BCA8`, bold 13.5px `#15202B` → semibold 13.5px `#2F3D48`,
  들림 효과 제거, 옅은 그림자 유지. 두 버튼 180×42px 동일.
- 「대표 미션 시연」 → 「대표 미션 살펴보기」. 코드 상수명과 스크린리더 레이블도 중립 표현으로.
- 후크↔설명 20→16px, 설명↔역할 카드 24→20px.
- 1440×900에서 문서 높이 900 = 뷰포트 900(스크롤 없음).

## 학습 미션 실행 (LOCK)
- 구조 라벨(원문·상황·지금 할 일·정리 항목 등) 11 → 12px, 13곳.
- 상태 배지 10/11px 혼재 → 11px 한 종, 7곳. 11px 안내 문장 3곳 → 12px.
  결과: 운영 화면에서 12px 미만 텍스트 0(남은 11px 1개는 로컬 전용 미리보기 버튼).
- 같은 위계 제목 18/20/24px 혼재 → 20px 한 종
  (첫 판단 화면 18→20, 산출 전 정리 24→20, 완료 24→20).
  제목을 두지 않는 단계(A2~A5·직접 옮기기)는 설계 의도라 그대로 둔다.
- 세로 리듬 −19px: 미션 레이아웃 상하 20→16, 진행바↔작업 영역 20→16,
  첫 화면 블록 간격 10→8. 첫 문항 화면이 919 → 900px가 되어 1440×900 첫 화면에 들어온다.
- 미션 로드 실패 시 데이터베이스 원문(`permission denied for …`)을 학습자에게 보여 주던 것을
  한국어 안내 문장으로 교체. 실패는 그대로 알리고 기술적 원인은 콘솔에만 남긴다.
- 미리보기 배너 제목을 제품 표현으로 교체. 「수행 기록 저장 안 됨」 고지는 유지.
- 미리보기 채우기 버튼 명칭을 「예시 답안 입력」으로 통일(화면·테스트·`docs/product` 정본).
  기능·라우트·저장 동작은 변경 없음.

## 유지(이번에 하지 않음)
- 진행바와 카드 상단 제목의 문구 중복 — 진행바는 내비게이션, 카드는 현재 작업 제목으로
  기능이 달라 유지하기로 결정.
- 색 값 정리, 컴포넌트 리팩터, 피드백 화면 레이아웃, 통역 화면 구조, 전역 토큰 도입,
  관리자 화면의 같은 패턴 3곳.

## 검증
- 1440×900 / zoom 100%: 첫 화면 900 · 첫 문항 900 · 문항 2~5 900 · 산출 전 정리 900 ·
  직접 옮기기 900.
- `npm run typecheck`, 단위 테스트 979 pass(3 skip), `npm run build` 통과. 신규 콘솔 오류 없음.
- AI 피드백·수정/유지/완료 단계는 실제 제출이 필요해 로컬에서 렌더하지 못했다 — 운영 확인 시 함께 본다.

LOCK 이후에는 blocker·기능 오류·오탈자·논문 불일치만 수정한다.
