# 주차 운영 배지 정렬과 명칭 정리

- 요청: 운영 현황의 배지 열을 맞추고 1·8·15주차를 오리엔테이션·중간고사·기말고사로 표시.
- 분류: `[단독 진행 적합]`. 소규모 UI 수정으로 로컬 확인·커밋까지만 수행한다.
- 원인: 각 행의 버튼 영역이 `auto` 너비여서 버튼 개수에 따라 배지 열의 시작점이 달랐다.
- 변경: 데스크톱의 공통 열 너비와 상태 배지별 최소 너비를 지정했다. 좁은 화면에서는
  세로로 배치하고 배지는 줄바꿈한다. 주차 선택 목록과 운영 현황은
  `1주차 오리엔테이션`, `8주차 중간고사`, `15주차 기말고사`로 표시한다.
- 저장된 주차 제목·수업자료 내용·평가 방식·편성·생성계약은 수정하지 않았다.

## 확인

- 기존 localhost 8099 HTTP 200 확인 후, 실제 페이지 컴포넌트에 합성 교과목 데이터를 넣어 화면을 확인했다.
- 1440px에서 15개 행의 세 상태 배지 열 좌표가 모두 일치했다. 선택 목록과 행의 세 명칭을 확인했다.
- 1280·1024·390px에서 가로 넘침 없음. 데스크톱·모바일 캡처 확인, 타입 검사 통과.
- 증거: `.tmp/week-alignment-smoke.json`, `.tmp/week-alignment-desktop.png`, `.tmp/week-alignment-mobile.png`.
- 운영 데이터 쓰기·전체 테스트·빌드·배포는 실행하지 않았다.
- 단순 정렬·표시명 변경이므로 research-trail은 갱신하지 않았다. 확인 필요 항목 없음.

## 논문 영향 3줄

1. 수치: 테스트 수·버전 변경 없음. 로컬 반영, 운영 배포 없음.
2. 화면: 주차별 수업 운영의 배지 정렬 및 1·8·15주차 표시명.
3. 프롬프트·계약: 변경 없음. 동결본 재발행 불필요.

## 사용자 승인 후 운영 반영

- 후속 요청: 사용자가 커밋·푸시·배포를 명시적으로 승인했다.
- 배포 대상은 UI 수정 `3ae66ce8`과 이 후속 기록이다. 기존 로컬 정렬·문구·모바일 확인을 재사용한다.
- PR의 필수 CI(타입·전체 테스트·운영용 빌드 등) 성공 확인 후 main에 병합하고,
  GitHub main 트리거로 Railway production에 반영한다.
- 최종 main SHA, CI 결과, Railway 배포 SHA와 운영 주소·배포 파일 확인 결과는
  이 변경을 포함한 GitHub PR 본문에 후속 근거로 남긴다.
- 배포 승인은 기능 범위를 확대하지 않는다. 연구 기록 추가나 동결 계약 재발행은 필요하지 않다.
