## 1. 7/22본의 구성 (코드 기준, `473b1235`)

- 흐름: ① 감각 쌓기(판단 문항 여러 개) → ② 적용(새 상황 산출 1회) → ③ 피드백 → ④ 수정.

  판정+교정 선택지(복수 정답) · 판정+이유+확신도 · 한 원문 5발화 각각 3단계 판정.
  코드 주석: 실제 미션은 3~4문항, 목표 6~8분(Roever: 문항이 많으면 시나리오를 대충 읽는다).
- 파일 머리의 **선택지 통제 제약 3줄**: 사실 정보·발화 의도는 원문과 동일 / 모두 문법적으로 성립 /
  차이는 목표 화용 요소(직접성·완화)에서만.
- 문항 장면(요청·중급·한→중, 모두 연구자 작성, 원어민 검토 전 초안): 지도교수 추천서 이메일
  (「请给我写」 지시형) · 카페 콘센트(사과 중첩 → 과잉) · 룸메이트 에어컨(把자 명령형 + 원문 이유 누락) ·
  조교 위챗(「喂」 과소 / 「尊敬的助教，恳请您告知…」 공문투 과잉) · 동아리 선배 위챗(알맞음) ·
  조원 자료 정리(과소 2·알맞음 2·과잉 1).
- 피드백: 의미와 의도 / 이번 화용 요소 / 다른 표현 가능성(「정답이 아니라 비교용」) 3영역.
  수정 범위는 피드백 결과별 4단계(전체 다시 쓰기·빠진 구간·목표 표현만·그대로 마쳐도 됨).
  마무리는 전이 원리 한 줄(「핵심 요청 앞에 짧은 포석, 뒤에 선택할 여지」).
- 학습자 라벨: 「너무 직접 / 알맞음 / 과잉 공손」. P·D·R은 화면에 노출하지 않고 설계 확인 표시만.

2. **폐기·축소의 다수는 사유가 기록돼 있다(사실).** 확신도·5후보 판정·복수 선택·channel 축은 각각
   부담·중복·중복 모델링 사유가 남아 있다. 과잉공손 전용 척도·자유 교정의 폐기 사유와 5점→4점 전환
   시점은 기록을 찾지 못했다.
3. **7/22본에도 이후 확인된 결함 유형이 있다(사실).** DEC-20260731-06이 도입 아크 목업에서 지적한

   7/22본을 무결한 기준으로 취급할 근거는 없다.

   범위가 문체·격식을 다루지 않는다고 보고했다.
