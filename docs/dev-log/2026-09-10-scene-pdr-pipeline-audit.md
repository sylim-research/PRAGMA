## 수정안의 범위 — 아직 구현하지 않음

1. **지금 반드시 해결:** 지정 화행·PDR 조건과 실제 사건의 양방향 대조. P는 직함·자신의
   수락 선택권·창구 처리 능력만으로 판단하지 않고 해당 참여자 관계의 실질적 권한을 본다.
   D는 접촉 이력, R은 화행별 상황 근거를 본다. 요청의 시간·노력·비용 기준을 전 화행에 복제하지
   않는다(생성계약 §3.1: 사과는 피해 심각도, 제안은 의향 충돌·수용 난이도·사안 중대성).
2. **지금 반드시 해결:** 호환되지 않는 시드·조건은 미션으로 확장하기 전에 보류한다. 기존
   16축 critic의 관련 결과를 실제 진행 조건에 연결한다. 초안 저장은 보존하되 의미 검토의
   누락·실패를 통과로 취급하지 않는다. 불확실한 근거는 검토 사유로 남긴다.
3. **지금 반드시 해결:** 역할 표기 제거의 광범위 명사 추정을 없애고 실제 인물·조사를 보존한다.
   자연어는 생성 단계에서 완성하며, 시드 계승·정규화 후의 최종 상황과 원문을 대조한다.
   화면에서 잘라낸 뒤에도 판단 근거가 남는지 확인한다. 이는 재생성보다 먼저 고칠 실행 경로다.
4. **완성 전 해결 권장:** 위 네 조사 반례, 초대 거절 사과의 행위자 역전, 직함만 있는 P,
   첫 연락/아는 사이의 D, 칭찬 high R 등 알려진 결함을 재발 방지 묶음으로 사용한다.

5. 이후 소수 대표 새 콘텐츠에서 생성→검수의 실제 결과를 확인한 뒤, 교과목 20개를 상황·원문뿐
   아니라 MJT 후보·정답·해설·참고안까지 검토하고 편성을 교체한다. 20~30이라는 수량 자체를
   타당성 기준으로 삼지 않는다. 기존 학습 기록과 구버전 콘텐츠는 보존한다.
