# 2026-10-04 화면 용어 표시 정리 5건

표시 문구만 바꾸었다. 승인 콘텐츠(문항 제목 포함)·저장된 수행 기록·프롬프트 본문·DB는 그대로다.

| 화면 | 이전 | 이후 |
|---|---|---|
| 교수자 최종 승인 · 감수 목록 | DCT · 직접 번역하기 | DCT형 통번역 과제 · 직접 번역하기 (꼬리표 칸을 넓혀 한 줄 유지) |
| 학습 미션 설계 요약 | MJT 문항 1~5 | MJT 판단 문항 1~5 (한 줄 유지) |
| 학습 미션 설계 요약 | 번역(통역) → AI 피드백 → 다듬기 | 번역(통역) → AI 피드백 → 재검토 |
| 대시보드 보유 콘텐츠 | MJT 문항 / 미션에 포함된 MJT 문항 | MJT 판단 문항 / 미션에 포함된 MJT 판단 문항 |
| 학습자 재검토 화면 제목 | 다시 다듬기 | 재검토 |
| 학습 미션 완료(수정 경로) | AI 피드백을 참고해 한 번 더 다듬어 최종 번역을 결정했습니다. | 번역을 수정한 뒤 최종 번역을 결정했습니다. (통역은 「통역」) |

유지 경로의 완료 문구는 바꾸지 않았다.

검증: `npm run typecheck` 통과, 관련 테스트 9개 파일 통과(감수 목록 기대값 갱신). 로컬 `/demo/mission`에서 재검토 제목과 수정 경로 완료 문구 확인. 교수자 화면은 배포 후 운영에서 확인한다.
