- 충실한 직접 표현은 적절이다 — 거절 MJT2(「그런데 이번 주말엔 못 가」)와 불만 MJT2(「빨리 해결해 주세요」)를 같은 원칙으로 뒤집었다. 더 완곡한 번역안이 *가능*하다는 것과 *필수*라는 것을 해설에서 구별한다.
- MJT5는 네 후보 모두 내용(요소·양태·화행 목적)을 보존하고 실현만 다르게. 거절은 그 조건에서 대역 오답을 만들지 못해 네 후보 전부 within으로 두었고, 감사·반대·불만·사과는 under/over 후보를 내용 통제로 만들 수 있었다.
- 3번 문항은 2번과 다른 장면·원문·장치로 신설한다(변환기가 이제 이 자리를 gap으로 보고한다, PR #189). 오늘 쓴 장치: 거절=결론 유무·사과 무게 / 사과=약속의 확정성 / 감사=조건부 보답의 확약화 / 반대=걱정 대상과 대안의 흐림 / 불만=추측의 단정화·요청의 완곡함.
