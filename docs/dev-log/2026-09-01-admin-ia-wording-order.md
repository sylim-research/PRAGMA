# 2026-09-01 · 관리자 메뉴 그룹명·강의 운영 순서 정리

## 배경과 판정

- 분류: **[교차검증 권고]**. 사용자·GPT·Codex가 현행 4그룹과 16개 링크를 유지하면서 일반
  관리자가 이해하기 쉬운 그룹명과 실제 학부 강의 운영 순서를 독립 검토했다.
- 기준: `origin/main` `c7fdcc0`에서 `codex/admin-ia-wording-order-2026-09-01` 브랜치를 만들었다.
- 기존 기능은 모두 고유한 역할이 있어 화면·라우트 삭제나 새 대분류가 필요하지 않다고 판정했다.
  다만 `학습 결과`는 현행 화면에 없는 성취도 분석을 암시하고, 학습자 관리는 실제 수업 화면보다
  앞에 두는 편이 강의 운영 흐름을 더 정확하게 나타냈다.

## 결정과 구현

- 그룹명을 `콘텐츠 설계·생성 기준`, `학습 콘텐츠 제작`, `강의 준비·운영`,
  `학습 기록·연구 자료`로 정리했다.
- 강의 준비·운영의 순서를 `15주 편성 → 학습자 승인·관리 → 주차별 수업 운영 → 실시간 학급 응답
  → 수업 데이터 백업·복원`으로 바꿨다.
- `실시간 학급 응답`은 수업 중 직접 진입이 필요한 독립 작업이므로 들여쓰기나 하위 메뉴로 만들지
  않았다.
- 백업·복원은 강의 운영 데이터 안전 기능으로 같은 그룹에 유지하고, 데스크톱 사이드바에서 앞에
  여백과 얇은 선만 두었다. `준비/진행/운영 지원` 소그룹이나 5번째 대분류는 만들지 않았다.
- 모바일 선택기는 같은 내비게이션 정본을 사용하므로 새 그룹명과 순서를 함께 반영하되, 선택 UI에
  불필요한 가상 계층은 추가하지 않았다.
