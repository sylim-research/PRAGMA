# 2026-10-04 대표 미션 화면 문구 정리

배포본의 대표 미션(데모 `/demo/mission`·실제 2주차 미션 1)을 용어대장·논리대장과 대조한 결과 중 화면 문구만 고쳤다. 콘텐츠(문항·해설·핵심 정리)와 학습 흐름은 그대로다.

- **초안·확정안의 화면 이름 통일**: 용어대장의 화면 표시명은 「최초 번역(통역) / 최종 번역(통역)」이고 본문 상태명(초안·확정안)과 섞지 않는다. 2026-10-03에 「최종안」을 고치며 화면 문장에 넣은 「확정안」·「초안」과 「첫 번역」을 모두 「최초/최종 번역(통역)」으로 맞췄다(미션 안내 「최종 번역을 내가 결정하기」, 재검토 「최종 번역을 결정하세요」, 「수정하지 않고 최초 번역 유지하기」, 완료 문구, 입력란 이름).
- **AI 피드백 제목**: 1차 피드백 카드 「번역 피드백」 → 「AI 피드백」(2차는 「수정안 AI 피드백」 그대로).
- **결과 문구 말투**: 이유가 기준과 같을 때 「기준 이유를 골랐습니다」 → 「기준 이유와 같습니다」(판단 문항의 「기준 판단과 같습니다」와 같은 꼴).
- **안내 문구**: 「나의 학습 기록」 → 실제 메뉴 이름 「내 기록」, 「현재 미리보기의 답안과 의견은 DB에 저장되지 않습니다」 → 「데모에서는 답안과 의견을 저장하지 않습니다」.

남은 것: 데모와 실제 미션의 콘텐츠 버전 불일치(MJT 판단과 이유·DCT)는 연구자 결정 대기(Fable 판정).
