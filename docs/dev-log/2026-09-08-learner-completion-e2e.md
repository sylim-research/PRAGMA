## 확인한 문제와 수정본

1. 완료 저장 실패 후 미션을 다시 완료해야만 재시도할 수 있었다. 러너가 확정 답안·판단 응답·교과목 귀속을 메모리에 유지하고 저장만 재시도하도록 연결했다. 저장 중 재시작과 완료 영역의 복귀 링크는 막는다. 새로고침·탭 종료 뒤 답안을 복원하는 기능은 이번 범위가 아니다.
2. 서버 저장 후 응답이 유실될 수 있으므로 같은 완료 화면의 재시도에 동일한 로그 UUID를 사용한다. 기존 PK를 사용하며 DB migration·RLS·upsert는 추가하지 않았다. unique 충돌은 해당 ID·현재 사용자·미션·최초/최종 답안으로 기존 행을 확인한 경우에만 성공으로 처리한다. 다른 충돌이나 조회 실패는 저장 실패로 유지한다.
3. 운영 완료 화면에서 화용 보완 판정을 받았는데도 강조 문구가 비어 있으면 ‘원문의 핵심 내용이 빠졌다’는 고정 설명이 나왔다. 이 경우 실제 보완 기준 이름을 표시하도록 수정했다. AI 판정·저장값 자체는 바꾸지 않는다.
