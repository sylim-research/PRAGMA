- 구조·후보 수·판정 구조는 변경하지 않았다(DEC-20260915-02 lock 유지).

## 방식
- 각 후보는 기존 행을 수정하지 않고 새 scenario 행으로 만들었다.
- 입력은 DB에 저장된 현재 미션 내용이다. 승인된 경로만 옛 값을 대조한 뒤 바꿨고, 바뀐 경로가 승인 목록과 다르면 등록 전에 멈추도록 했다.
- DCT 과제는 DB 저장본을 그대로 썼다(원본 코어에서 다시 채우지 않음).
- 등록 뒤 기존 절차대로 품질 점검 → 규칙 검사 → 최종 검수 자료 준비를 거쳐 교수자 승인 대기에서 멈췄다. 독립 검토 요청·승인·편성은 하지 않았다.
