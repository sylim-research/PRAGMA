## 핵심 판단

이번 묶음에서 추가 개발을 요구하는 명백한 불일치는 확인하지 않았다. **한·중 거절의 상황/표현 자료, 국내 AI 피드백·번역수업 비교, 판정·척도 해석의 경계**를 우선 집필 후보로 남긴다.

- 이명희(2009)는 한·중 모어화자의 거절 표현과 P·D·R 조합을 사용한 상황설계의 직접 자료다. 표현 빈도·상황 셀을 앱의 정답표·척도 검증으로 바꾸지 않는다.
- Taguchi(2011)의 과잉 공손 논점과 곽자랑 외(2018)의 저부담 조건에서의 높임 효과는 서로 다른 언어·조작·종속변수다. 단순한 반대 결과도, ‘저부담이면 덜 공손하게’라는 규칙도 아니다.
- 강병규(2025)·김혜림(2026)은 국내 비교 사례 후보다. 특정 연구의 분석 제외를 분야 전체의 공백으로, 관찰된 학습자 판단을 PRAGMA 효과로 확대하지 않는다. 둘 다 원문 미대조다.
- Hu 외(2023)는 의미와 화용 해석, 정답과 추론 방식의 구별을 보강한다. 현재 모델의 성능·생성 설명의 정확성을 직접 검증한 연구가 아니다.
- 장민정(2018)·Dai(2023)는 기존 맥락 논점에 병합한다. **C인 Dai·Roever(2026)·Culpeper(2011)는 본문 근거·개발 후보에서 제외 유지**한다. 파일을 삭제하거나 재확보하지 않는다.

## 카드 해석 보정과 재검증을 생략한 근거

1. **102 회귀:** §1 인용6은 ‘기분 좋은 관계’ 모국어만 수정 R²=.152, 성별 추가=.150, ‘부담되는 관계’ 모국어만=.138, 성별 추가=.193으로 적는다. 머리말의 ‘모국어 설명력15.2%·19.3%’와 맞지 않는다. **.193을 모국어 단독 기여로 인용하지 않는다.** 이번 집필 후보에는 수치를 쓰지 않고 카드·대장도 수정하지 않았다. 내부 불일치 확인에 PDF 재독은 필요하지 않다.
2. **103 확인 범위:** 대장의 `pp.453–471`·정독 표기와 §1b의 ‘과잉 공손 사례·척도 문구 쪽수 확인 필요’가 공존한다. 전자를 근거로 후자의 위치까지 확보됐다고 쓰지 않는다. 평정자 변이의 기존 확인 구간은 활용 후보로 두고 특정 예문을 쓸 때만 추가 대조한다.
3. **106 해소된 항목:** 옛 §1b/말미 대기 문구보다 추가 구간4와 대장의 **pp.9–11 확인 기록**을 따른다. 181명 참여→179명 분석, 부담도60·불쾌감60·발화가능성59, 본실험 별도58명도 이미 기록돼 있다. 절차·문항수·저고 기준을 재대기시키지 않는다. 다만 카드의 ‘즉시 인용 가능’은 연구자의 주장 문장 승인과 다르다.

5. **107 적용 추론:** 이해 정답과 추론 방식의 구별은 기존 설명 검토를 보강할 간접 이유다. ‘AI 해설의 타당성 직접 검증’이나 9화행의 난도 순위로 바꾸지 않는다.

## 논문 집필에 재사용할 연결

아래는 승인 본문이 아니라 **주장 방향**이다. 앱 구현은 현행 정본·소스·기록, 학술 주장은 문헌의 확인 구간으로 각각 뒷받침한다.

- **맥락·표현 설계:** ‘P·D·R을 사용한 거절 상황설계와 한·중 표현자원의 차이를 참고해, 형식·빈도만으로 적절성을 정하지 않는 현행 설계를 사후 점검했다.’ 104 확인 구간과 이번 로그가 근거다. 2수준 설계를 앱3수준·인과효과 검증으로 바꾸지 않는다.
- **판정 범위:** ‘참고 판정은 맥락과 실제 표현을 근거로 설명하며 평정 기준의 차이와 불확실성을 구분한다.’ 103은 사람 평정의 변이,107은 이해 정답/추론,106은 부담 조작 절차의 보조 근거다. PRAGMA 척도·AI 해설의 공동 타당화가 아니다.
- **AI 교육 비교:** ‘중국어 AI 오류교정과 중→한 번역수업을 과업·모델 역할·학습자 판단·수집 자료의 범위로 비교한다.’ 105·109 비교 문장과 쪽수는 **확인 필요**. 학습자 선택권만으로 AI 오류 해결·효과를 주장하지 않는다.
- **DDR 과정:** ‘101–110 카드의 사후 점검에서는 이미 반영된 맥락 중심 설명과 학습 흐름을 유지하고 직접 거절 자료·비교 사례·측정 범위의 제한을 집필 후보로 기록했다. 기존 기능 재개발과 새 평가 구인은 필요성이 확인되지 않아 추가하지 않았다.’ 근거는 **이번 작업 기록**이며 문헌의 실증 결론을 대신하지 않는다.

**원문 미대조→원문확인→인용가능**과 주장 문장별 `human_approval`을 구별한다. 확인된 구간을 반복 대조하지 않되 최종 인용·문장 승인은 연구자가 한다. 카드의 추론·쪽수 미확정·C 제외를 승인 근거로 바꾸지 않는다.
