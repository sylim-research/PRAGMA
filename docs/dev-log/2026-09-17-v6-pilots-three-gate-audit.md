## 발견 — v5 생성기의 편향: 「적절 = 원문보다 더 많이/세게 말하기」
- 거절: 원문에 이유가 없는 문항에서 정답이 전부 사유를 지어냈다(다른 계획·다른 일정·가족 모임·다음 기회).
  해설과 핵심 정리가 학습자에게 「이유를 붙여라」고 가르쳤다. 강화 사례 15.
- 사과: 원문만큼 옮긴 안을 「책임 인정 부족」으로 오답 처리하고, 「정말 죄송·더 철저히」처럼 강화한 안을 BEST로 두었다.
  원문에 없는 「~로 불편을 드려」가 후보·참고안 5곳에 공식처럼 붙어 있었다. 강화 사례 11.
- 두 표본에서 「혼입」 13자리 — 충실성 결함(발명·누락)이 대역 언어(「장황」「책임 인정 부족」「관계적 부담」)로 포장돼 있었다.
  **감사의 성과는 이 포장을 벗긴 것**이다.

## 원칙 (3차 확정)
- Gate A 출발어–장면 정합(원문·상황문·관계·PDR) → Gate B 충실성(핵심 내용 보존·발명 금지, 대역 판정의 선행 조건)
  → Gate C 목표어 자연성(오답도 자연스러운 오답). 순서대로.
- 대역은 핵심 내용을 유지한 채 화행의 대인적 힘이 과소/적정/과잉으로 실현됐는지만 본다.
  **「under = 누락, over = 발명」 등식은 기각**(2차에서 내가 세웠다가 3차에서 폐기) — 대역이 충실성으로 무너진다.
- 비명제적 완충(유보·사과·유감)도 자유 추가 자원이 아니다. 유보·양태·어순·격이 먼저, 별도 화행 자원을 보태려면 명시적 근거.
- 저장 키·PDR은 전제가 아니다. Gate 통과 뒤 독립 재판정. 장면을 PDR에 맞춰 고쳐 PDR을 정당화하지 않는다(2차에서 내가 그렇게 했다가 철회).
- 카탈로그 `fidelity_note` v2 = 위 원칙 문안(이 PR).
