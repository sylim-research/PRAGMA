## 실제 재현과 원인

- 운영의 AI 한중 화용 통번역 6주차에서 수업자료 링크를 클릭하면 hash만 바뀌었다.
  대상 details는 닫힌 상태였고 viewport 기준 top이 약 1278px로 화면 아래에 남았다.
  React Router의 같은 페이지 링크에 상세 열기·스크롤 처리가 없었다.
- 같은 주차 미션 링크는 `courseId`·`weekNo`만 보내고 `assignmentId`를 누락했다.
  운영 러너에서 ‘교과목 또는 배치 ID가 올바르지 않습니다’ 오류를 확인했다.
- 응답 분포 링크 자체는 정상 이동했다. 다만 모든 진입에 고정 예시를 기본 표시해
  선택 미션과 다른 분포가 나왔다. 실제 데이터로 전환한 6주차 첫 미션은 완료 응답 0명이었다.
  사용자의 브라우저에서 클릭 자체가 차단되는 현상은 재현하지 못했다.

## 수정

- 주차 자료 조회가 완료되면 `#weekly-material-detail` 대상의 검수 상세를 열고 포커스·스크롤을 이동한다.
  다른 주차 선택, 직접 링크 진입, 같은 링크 재클릭을 처리한다.
- 운영 목록과 하단 번역·통역 미션 링크 모두 실제 편성의 배정 ID를 포함한다.
  배정 ID가 없는 경우 불완전한 수행 URL을 만들지 않고 해당 교과목 주차로 연결한다.
- 특정 교과목·미션을 지정한 응답 분포 진입은 실제 데이터를 기본 표시한다.
  응답이 없으면 기존 수행 기록 없음 안내를 표시한다. 일반 메뉴 진입의 예시와 명시적 예시 전환은 유지한다.
