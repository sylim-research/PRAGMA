## 변경

- MJT3 수정 버튼의 최소 폭을 해제하고 긴 중국어와 해설이 버튼 폭 안에서 줄바꿈되도록 했다. 모바일에서는 선택·권장 배지를 표현 아래에, 640px 이상에서는 기존처럼 표현 옆에 표시한다.
- 직접 산출 전 요약의 `truncate`를 제거했다. 표현과 판단 근거가 화면 폭에 맞춰 여러 줄로 표시된다. 문항별 표현 하나·근거 하나라는 정보 범위와 실제 문장은 유지했다.
- 학습 기록의 9화행 지도를 모바일 2열, 640px 이상 3열로 표시한다.
- 학습자 구조 정본과 정본 인덱스의 ‘한 줄’ 설명을 폭에 따른 줄바꿈 허용·판단 근거 전체 표시로 명확히 했다. 생성 프롬프트·데이터 계약은 바꾸지 않았다.

## 검증

- `npm run typecheck` 통과.
- 기존 관련 4파일 26 tests 통과: `CanonicalMissionRun.runtime`, `.reason`, `.connections`, `LearnerRecords`. 새 CSS 클래스 유무만 확인하는 테스트는 추가하지 않았다.
- 변경 TSX 2파일 ESLint 오류 0. 수정하지 않은 export·hook 구간의 기존 경고 6건은 유지된다.
- 최초 Vitest 시작은 연결된 node_modules의 esbuild가 샌드박스에서 경로를 읽지 못해 실패했다. 권한 확대로 같은 검사를 다시 실행하여 통과했다.
- 실제 브라우저의 로컬 DEV preview로 MJT3의 최초 판단·수정안 선택 전·선택 후·확인 후를 조작했다. 긴 중국어 수정안 및 ‘내 선택’·‘권장 수정안’ 배지를 함께 확인했다.
  - 360px: 문서 `clientWidth=scrollWidth=345`, 수정 버튼 `clientWidth=scrollWidth=259`.
  - 390px: 문서 `clientWidth=scrollWidth=375`, 수정 버튼 `clientWidth=scrollWidth=289`.
  - 1280px: 문서 `clientWidth=scrollWidth=1265`, 수정 버튼 `clientWidth=scrollWidth=722`.
- 요약 5개는 360·390px에서 각 문단의 가로·세로 잘림 없이 두 줄로 읽혔고, 1280px에서는 한 줄로 표시됐다. 실제 문장·화살표 뒤 판단 근거·강조 표시를 확인했다.
- 기록은 기존 `LearnerRecords` 컴포넌트를 일회성 로컬 fixture에 직접 마운트하고 기존 localhost 시연 자료로 확인했다. 360·390px 2열, 768·1280px 3열이며 아홉 제목 모두 한 줄, 문서 가로 넘침 0이었다. fixture는 점검 후 제거했다.
- 점검은 모바일 폭의 데스크톱 브라우저 렌더링이다. 실제 휴대폰의 키보드·음성 인식·저장 종단 검증은 남아 있다. 이전 운영 DEMO와 이번 로컬 preview의 문항 내용이 다르므로 넘침 수치의 직접 전후 비교로 제시하지 않는다.
- 표시 변경 범위에 맞춰 기존 관련 검사와 실제 렌더링을 확인했다. 전체 테스트·production build는 이번 로컬 수정에서 다시 실행하지 않았다.
