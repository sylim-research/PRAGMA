  - 화행 균등 배분 버그 수정 — 번역·통역 나머지가 모두 앞 화행에 몰리던 것(18건 → 3·3·3·3·2·1·1·1·1)을 이어서 배정(화행당 2건).
  - 여러 화행에 쓰이는 주제 17개의 장면 시드를 화행 중립 문장으로 교체(행위자 방향은 유지). 시드가 다른 화행을 지시해
