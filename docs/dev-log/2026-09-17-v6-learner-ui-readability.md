# 2026-09-17 · v6 학습자 화면 가독성 4건 + 마지막 콘텐츠 사이클

## 콘텐츠 (DB, 새 후보 3건)
교수자 체험 검토 의견을 외부 자문과 교차 검토한 뒤, 이번이 E2E 전 **마지막 콘텐츠 사이클**임을
정하고 두 가지만 반영했다. 변경 경로는 미션당 2개다.

- MJT5 지시문을 세 미션 공통으로 교체: 「각 표현을 읽고, 이 상황에서 어떻게 들리는지 판단해 보세요.」
  - 옛 문구(「네 번역안을 각각 스펙트럼 위에…」)는 통역 미션에 안 맞고 요청 화행에 묶여 있었다.
  - 「같은 위치에 여러 표현을 놓아도 됩니다」는 삭제했다. 화면이 이미 표현마다 독립 3지선다라
    문장으로 동작을 해설할 필요가 없다.
- DCT 참고 표현을 1개 → 2개로. 「단일 정답이 아닌 복수의 방어 가능한 산출」이라는 설계를
  화면에서 드러내기 위한 것이다. 생성 계약으로 「항상 2개」를 만들지는 않는다.

기각한 것: 표현 메모에 L1 전이(한국어→중국어 대응) 줄 추가 — 제안된 대조
(`确认/核实`·`缺席/缺勤`·`传/发`)가 맥락에 따라 갈려 근거가 충분하지 않았다. 1번·3번 DCT 원문
손질 — 개선 여지는 있으나 코어·focal segment·단어 힌트가 연쇄로 바뀌고 E2E blocker가 아니다.

E2E 전 수정 허용 기준을 네 가지로 좁혔다: 의미 오류 / 판정 오류 / 상황·사실 모순 / 수행 차단.

## 화면 (코드)
1. **도입 안내** — 3×2 번호 카드 → 세로 1열. 「표현 판단」 다섯 활동은 제목만, 「직접 번역」은
   「다른 상황의 원문을 직접 번역하기」 + 한 줄. 활동 수를 세는 표기를 없애 다섯 판단 뒤에
   직접 산출이 온다는 흐름이 배치로 드러나게 했다.
2. **MJT4 결과** — 내 수정 → 화용 해설 → 참고 표현 → 다른 맥락 → 표현 메모 순으로 바꾸고,
   표현 메모를 별도 블록으로 뺐다. 이전에는 해설과 메모가 한 `<p>`에 들어가 줄바꿈이 죽어
   한 문단으로 읽혔다. 콘텐츠는 그대로 두고 화면에서만 가른다(`splitExpressionMemo`).
3. **4점 척도 안내** — 답한 뒤에만 「대표 판정: X · Y도 가능한 판단입니다.」를 보여 준다.
   답하기 전에 알리면 4점 판단 자체가 무력해진다.
4. **문항 상황 문장** — 14px 연회색 → 15.5px medium·진한 남회색. 레이아웃은 그대로.

번들 미리보기 견본의 MJT5 문구도 저장된 미션과 같게 맞췄다.
