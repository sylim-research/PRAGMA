# 2026-10-01 학습 미션 확정 버튼·해설 표기 정리

## 변경
- MJT 응답을 잠그는 버튼 이름을 「확정하기」로 통일했다. 판단 확인하기 → 판단 확정하기(MJT1·표현 비교), 교정안 확인하기 → 수정안 확정하기(수정안 고르기), 수정안 제출하기 → 수정안 확정하기(직접 고치기). 같은 행위에 세 동사가 섞여 있었다.
- 「교정안」은 학습자 화면에서 쓰지 않는 용어라 「수정안」으로 맞췄다.
- 표현 비교·수정안 후보의 해설(`note`)이 백틱을 그대로 노출하던 문제를 고쳤다. 문항 해설과 같은 `RichLine` 렌더러를 쓰도록 했다.
- 재검토 화면 안내문이 화면에 없는 「내 판단 남기기」 버튼을 가리키던 문구를 실제 경로(이전 화면의 「이대로 확정」)로 바꿨다. `MissionDissentPanel`은 현재 화면에서 쓰이지 않는다.

## 범위
- 학습 흐름·완료 조건·저장 구조는 바꾸지 않았다. 「번역 제출하기」「수정안 다시 확인하기」는 AI 피드백을 요청하는 다른 행위라 그대로 두었다.

## 확인
- `npm run typecheck` 통과, `CanonicalMissionRun` 테스트 9파일 51건 통과.
- 로컬 `/demo/mission`에서 MJT 5문항 버튼명, 표현 비교 해설 렌더링, 재검토 안내문을 확인했다.

## 추가(같은 날) — 이모지 표식을 선 아이콘 칩으로
- 학습 미션 화면의 이모지(💡 해설, ✅ 참고 표현·가능한 수정 예시, 🔄 다른 맥락에서는?, 📒 데모 학습 기록)와 로켓·반짝임 아이콘(학습 미션 시작하기, 답안 자동 채우기, 피드백 「좋음」)을 lucide 선 아이콘으로 바꿨다. 초점을 만드는 역할은 유지하되, 컬러 이모지 대신 절의 바탕색 계열을 따르는 작은 아이콘 칩(`SectionIcon`)과 해설 꼬리표(`NoteTag`·`NoteHeading`)로 통일했다.
  - 해설 = 펼친 책(BookOpenText), 참고 표현 = 인용 부호(Quote), 다른 맥락 = 좌우 화살표(ArrowLeftRight), 데모 기록 = 목록판(ClipboardList), 답안 자동 채우기 = 펜(PenLine), 피드백 통과 = 체크.
- 완료 카드 문구를 「내 번역, 완성!」→「내 번역 완성」, 「~만들었어요/확정했어요」→「~결정했습니다/확정했습니다」로 바꿨다. 「다른 맥락에서는?」 말풍선 아래의 「보냄」 표식은 지웠다.
- 참고 표현 상자의 해설 줄도 후보 해설과 같은 「해설」 꼬리표를 쓴다.
- 확인: typecheck 통과, `CanonicalMissionRun` 테스트 51건 통과, 로컬 데모 전 구간에서 이모지 문자 0건.
