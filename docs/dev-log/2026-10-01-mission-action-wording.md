# 2026-10-01 학습 미션 확정 버튼·해설 표기 정리

## 변경
- MJT 응답을 잠그는 버튼 이름을 「확정하기」로 통일했다. 판단 확인하기 → 판단 확정하기(MJT1·표현 비교), 교정안 확인하기 → 수정안 확정하기(수정안 고르기), 수정안 제출하기 → 수정안 확정하기(직접 고치기). 같은 행위에 세 동사가 섞여 있었다.
- 「교정안」은 학습자 화면에서 쓰지 않는 용어라 「수정안」으로 맞췄다.
- 표현 비교·수정안 후보의 해설(`note`)이 백틱을 그대로 노출하던 문제를 고쳤다. 문항 해설과 같은 `RichLine` 렌더러를 쓰도록 했다.
- 재검토 화면 안내문이 화면에 없는 「내 판단 남기기」 버튼을 가리키던 문구를 실제 경로(이전 화면의 「이대로 확정」)로 바꿨다. `MissionDissentPanel`은 현재 화면에서 쓰이지 않는다.

## 범위
- 학습 흐름·완료 조건·저장 구조는 바꾸지 않았다. 「번역 제출하기」「수정안 다시 확인하기」는 AI 피드백을 요청하는 다른 행위라 그대로 두었다.

## 추가(같은 날) — 표현 비교 판정 문법·수정안 꼬리표·중국어 줄바꿈
- **표현 비교(MJT3) 판정을 선택지 위로 옮겼다.** 선택지 아래 「✕ 허용 판단 · 상황에 맞음」 줄은 ✕(내 선택이 틀림)와 글(허용 답)이 다른 대상을 가리켜 이중 메시지가 됐다. 「판정은 선택지 위에서 끝낸다」(DEC-20260918-03)에 맞춰, 내가 고른 칩에 ✓/✕, 허용되는 칩에 「허용 판단」 꼬리표만 붙인다. 아래에는 해설만 남는다. 스크린리더용 판정 문장은 유지.
- 수정안 선택(MJT4) 꼬리표 「가능한 선택」 → 「타당 수정」(4글자, 데이터의 `valid`와 대응).
- **중국어 줄바꿈 교정.** 앞서 넣은 `text-wrap: balance`가 한자 사이 어디서나 끊어 我家|的快递, 能|不能처럼 어절 내부가 갈렸다. `.font-zh`에 `word-break: keep-all`(구두점 뒤에서만 끊음) + `overflow-wrap: anywhere`(한 절이 한 줄보다 길 때만 글자 단위)를 더하고, 입력칸에서는 balance를 껐다.
- 확인: typecheck 통과, 테스트 51건 통과. 데모 전 구간(MJT 1~5, 핵심 정리, 번역 입력, 피드백 1·2차, 재검토 입력, 완료)의 중국어 줄바꿈을 글자 단위로 실측 — 1500px·1280px 폭 모두 8곳 전부 구두점(，。？) 뒤, 어절 내부 0건.

- 이어서 1.75px도 무겁다는 판단으로 1.6px(border 1px + ring 0.6px)로 재조정.

- 미션 안내 마지막 손질: 두 띠 오른쪽에 응답 방식 표지 「선택형」(목록 아이콘)·「작성형」(펜 아이콘) — 처음 보는 학생·심사위원에게 MJT=고르기, DCT=직접 쓰기라는 모드 차이를 먼저 알린다. 가운데 화살표는 글자 크기 아이콘에서 띠 중앙을 잇는 잉크색 연결선+화살촉으로. 보조 설명은 14px 중간 굵기·진한 회청색(#3F4A57)으로 대비를 올렸고, 이름 열을 5.75rem으로 줄여 1280px 폭에서도 잘리지 않게 했다(「번역안 하나의 상황 적절성」→「번역안 하나의 적절성」).

- 피드백 「수정 권장」을 호박색에서 MJT 오답과 같은 빨강 계열(연한 빨강 바탕·빨간 왼쪽 선·적갈색 글자)로 — 호박색은 허용·참고의 색이라 「고쳐야 한다」가 전달되지 않았다. 「수정 필요」와 같은 색. 재검토 화면의 권장 상자도 같이.
- 단어 힌트 칩: 흰 바탕+테두리 → 미색(#F8F6EE) 알약, 테두리 없음. 흰 패널 위 흰 카드라 대비가 없었다.
- 응답 방식 표지 「작성형」 → 「산출형」(통역은 쓰지 않으므로). 통역 미션은 펜 대신 마이크 아이콘.

## 추가(같은 날) — 색은 선과 배지에만
- 판정 문법 원칙: 정답·오답·수정 권장 모두 **흰 면 + 색 테두리 + 색 배지**. 오답 선택지(MJT1~4)·판정 배너·피드백 기준 카드 3장·수정 권장 상자의 분홍/연초록 면 채움을 걷었다. 정답은 흰 면인데 오답만 분홍 면이라 부호화가 비대칭이었고, 피드백 화면은 색면 카드가 모여 「경고 벽지」가 됐다. 시스템 오류 알림(저장 실패)만 분홍 면 유지.
- 시작 화면: 응답 방식 표지를 두 띠 모두 흰 알약+잉크 글자로(「산출형」이 노랑 위 반투명이라 흐렸다). 연결 화살표를 손그림 SVG에서 아이콘 세트의 긴 화살표(MoveRight, 1.75 획)로. 카드 좌우 여백과 가운데 간격을 줄여 두 칼럼 폭 315px(1280 화면).
- 상황 상자: 회색(#F3F3F0) → 모래색(#F2EEE3), 「상황」 표제 잉크색 12px. 팔레트 밖 한색을 걷고, 무대 지시문답게 종이색을 달리했다.
- 단어 힌트: 토글 오른쪽으로 가로 펼침(입력창 바로 아래 한 줄에서 보며 입력). 칩은 DM 말풍선과 같은 블루(#326BD6)·흰 글자·비대칭 모서리 — 둘 다 「밖에서 오는 반가운 것」. 토글은 14.5px 굵은 잉크 + 노란 원형 전구로 키웠다.
- 시작 화면: 국면 띠 세로 폭을 조금 늘림(py-2.5→3.5). 보조 설명을 명사형에서 학습자가 할 일을 말하는 「~하기」로 — 상황에 맞는지 판단하기 / 왜 그런지 근거 고르기 / 여러 표현을 견주어 보기 / 더 나은 수정안 고르기 / 번역안을 직접 고쳐 쓰기 / 새 원문을 직접 옮기기 / AI 피드백 확인하기 / 고칠지 유지할지 정하기. 1280px에서 잘림 0.
