# 2026-10-01 학습 미션 확정 버튼·해설 표기 정리

## 변경
- MJT 응답을 잠그는 버튼 이름을 「확정하기」로 통일했다. 판단 확인하기 → 판단 확정하기(MJT1·표현 비교), 교정안 확인하기 → 수정안 확정하기(수정안 고르기), 수정안 제출하기 → 수정안 확정하기(직접 고치기). 같은 행위에 세 동사가 섞여 있었다.
- 「교정안」은 학습자 화면에서 쓰지 않는 용어라 「수정안」으로 맞췄다.
- 표현 비교·수정안 후보의 해설(`note`)이 백틱을 그대로 노출하던 문제를 고쳤다. 문항 해설과 같은 `RichLine` 렌더러를 쓰도록 했다.
- 재검토 화면 안내문이 화면에 없는 「내 판단 남기기」 버튼을 가리키던 문구를 실제 경로(이전 화면의 「이대로 확정」)로 바꿨다. `MissionDissentPanel`은 현재 화면에서 쓰이지 않는다.

## 범위
- 학습 흐름·완료 조건·저장 구조는 바꾸지 않았다. 「번역 제출하기」「수정안 다시 확인하기」는 AI 피드백을 요청하는 다른 행위라 그대로 두었다.

## 확인
- `npm run typecheck` 통과, `CanonicalMissionRun` 테스트 9파일 51건 통과.
- 로컬 `/demo/mission`에서 MJT 5문항 버튼명, 표현 비교 해설 렌더링, 재검토 안내문을 확인했다.

## 추가(같은 날) — 이모지 표식을 선 아이콘 칩으로
- 학습 미션 화면의 이모지(💡 해설, ✅ 참고 표현·가능한 수정 예시, 🔄 다른 맥락에서는?, 📒 데모 학습 기록)와 로켓·반짝임 아이콘(학습 미션 시작하기, 답안 자동 채우기, 피드백 「좋음」)을 lucide 선 아이콘으로 바꿨다. 초점을 만드는 역할은 유지하되, 컬러 이모지 대신 절의 바탕색 계열을 따르는 작은 아이콘 칩(`SectionIcon`)과 해설 꼬리표(`NoteTag`·`NoteHeading`)로 통일했다.
  - 해설 = 펼친 책(BookOpenText), 참고 표현 = 인용 부호(Quote), 다른 맥락 = 좌우 화살표(ArrowLeftRight), 데모 기록 = 목록판(ClipboardList), 답안 자동 채우기 = 펜(PenLine), 피드백 통과 = 체크.
- 완료 카드 문구를 「내 번역, 완성!」→「내 번역 완성」, 「~만들었어요/확정했어요」→「~결정했습니다/확정했습니다」로 바꿨다. 「다른 맥락에서는?」 말풍선 아래의 「보냄」 표식은 지웠다.
- 참고 표현 상자의 해설 줄도 후보 해설과 같은 「해설」 꼬리표를 쓴다.
- 확인: typecheck 통과, `CanonicalMissionRun` 테스트 51건 통과, 로컬 데모 전 구간에서 이모지 문자 0건.

## 추가(같은 날) — 연구자 피드백 7건 반영
- **수정 화면에서 첫 산출 유지로 되돌아가기**: 「수정하기」로 들어간 뒤에도 「수정하지 않고 첫 번역 유지하기」 버튼이 항상 보인다. 누르면 피드백 화면으로 돌아가며, 수정 권장인 경우 「이대로 확정」의 이유 입력칸이 열린 채로 돌아간다. 이전에는 이견을 이미 남긴 경우에만 보였다.
- 「수정안 다시 확인하기」 → 「수정안 제출하기」. 「번역 제출하기」와 같은 행위(AI 피드백 요청)라 같은 동사를 쓴다.
- 참고 표현·가능한 수정 예시의 인용 부호 아이콘을 여는 방향(“)으로 돌렸다.
- 완료 화면 참고 표현의 중국어 굵기 600→500.
- `.font-zh` 블록에 `text-wrap: balance` — 중국어 표시 문장이 두 줄로 꺾일 때 마지막 줄에 한두 글자만 남지 않도록 줄 길이를 고르게 나눈다. 입력칸(textarea)에는 브라우저가 적용하지 않는다.
- 「다른 맥락에서는?」 말풍선을 파랑(#0B63CE)+흰 글자에서 팔레트 안의 회청색(#EDF1F6)+남색 글자로 바꿨다. 페이지에서 유일한 채도 높은 한색이라 해설·참고 표현보다 먼저 눈에 들어오던 문제.
- 단어 힌트를 요약 줄 아래로 세로 펼침. 꺾쇠(아래) 방향과 실제 펼침 방향을 맞췄다.
- 확인: typecheck 통과, `CanonicalMissionRun` 테스트 51건 통과, 로컬 데모에서 되돌아가기 경로·힌트 배치·말풍선 색 확인.

## 추가(같은 날) — 미션 안내 설계도 재구성·단계 이름 한 벌
- 미션 안내를 두 국면 카드로 재구성했다. 「Ⅰ 적절성 판단 · MJT · 메타화용적 판단 과제」와 「Ⅱ 직접 번역 · DCT형 통번역 과제」를 같은 높이·같은 머리띠로 나란히 두고, 가운데 화살표 하나로 판단에서 산출로의 전환을 표시한다. 손그림 중괄호는 지웠다(묶음 기호라 「다섯 개를 하나로 압축」으로 읽혔다).
- 오른쪽 카드의 단계를 진행 막대와 같은 이름(번역하기·피드백·재검토)으로 펼쳤다.
- MJT 다섯 단계 이름을 앱 전체에서 한 벌로 맞췄다: 표현 판단 · 판단과 이유 · 표현 비교 · 수정안 선택 · 직접 수정. 미션 안내·진행 막대 소제목·「다음:」 버튼·핵심 정리가 같은 이름을 쓴다. 각 단계 옆에 역할 한 줄(예: 「같은 원문의 여러 표현을 나란히」)을 붙였다.
- 미션 안내와 핵심 정리는 노트북 화면(1600×830)에서 스크롤 없이 한 화면에 들어오도록 간격을 줄이고, 남는 높이는 글자 크기로 채웠다. 핵심 정리는 카드 다섯 장을 한 패널의 표처럼(번호 · 이름 칸 고정 · 요약) 바꿨다.
- 확인: typecheck 통과, 미션 관련 테스트 220건 중 219건 통과 — 남은 1건은 병렬 실행 시에만 나는 5초 시간 초과로, 단독 실행에서 통과한다.

## 추가(같은 날) — 설계도를 배포본의 알약 언어로 되돌림
- 두 국면 카드(테두리·색 띠 머리글·행 구분선·Ⅰ/Ⅱ 칩)를 걷어내고, 배포본과 같은 알약 목록으로 돌아갔다. 국면 구분은 선이 아니라 알약 바탕색(판단 = 회청색, 산출 = 호박색)으로 한다 — 연구자가 색 구분은 유지하라고 했다.
- 단계 이름 열 폭을 고정해 보조 설명이 모두 같은 x에서 시작한다. 보조 설명은 명사형 12자 이내(예: 「같은 원문의 표현 대조」). 오른쪽 3행은 왼쪽 높이에 맞춰 늘리지 않는다.
- 글자 크기를 한 단계 내렸다(이름 15.5px semibold, 설명 13.5px). 1500×1010 화면에서 카드 아래 끝 670px.

## 추가(같은 날) — 꼬리표·패널 규격·MJT5 정렬
- 꼬리표 「가능한 판단」 → 「허용 판단」. 내 선택 · 기준 판단 · 허용 판단 · 핵심 이유가 모두 4글자. 뜻: 기준 판단과 다르지만 콘텐츠가 설정한 적절성 범위에 포함되는 인접 판단. 외부 AI 교차검토에서 같은 후보가 추천됐다(「대안 판단」은 적절성이 불분명, 「근접 판단」은 「아쉬운 오답」으로 읽힐 위험).
- 답 확정 뒤 형제 패널(해설·참고 표현·가능한 수정 예시·완료 화면 참고 표현)의 제목을 한 규격으로: 24px 아이콘 칩 + 16px 굵은 제목. 참고 표현 패널에 투명 4px 왼쪽 띠를 넣어 해설(호박색 띠)과 글자 시작점을 맞췄다.
- MJT5(직접 수정) 입력창을 MJT1~4의 선택지 버튼과 같은 카드 여백선으로 옮겼다. Q 줄과 주의문만 들여쓴다. 입력창·해설·참고 표현의 왼쪽 끝이 같은 선에 선다.
- 확인: typecheck 통과, `CanonicalMissionRun` 테스트 51건 통과, 로컬에서 세 요소의 왼쪽 끝과 제목 규격 일치를 수치로 확인.

## 추가(같은 날) — 표현 비교 판정 문법·수정안 꼬리표·중국어 줄바꿈
- **표현 비교(MJT3) 판정을 선택지 위로 옮겼다.** 선택지 아래 「✕ 허용 판단 · 상황에 맞음」 줄은 ✕(내 선택이 틀림)와 글(허용 답)이 다른 대상을 가리켜 이중 메시지가 됐다. 「판정은 선택지 위에서 끝낸다」(DEC-20260918-03)에 맞춰, 내가 고른 칩에 ✓/✕, 허용되는 칩에 「허용 판단」 꼬리표만 붙인다. 아래에는 해설만 남는다. 스크린리더용 판정 문장은 유지.
- 수정안 선택(MJT4) 꼬리표 「가능한 선택」 → 「타당 수정」(4글자, 데이터의 `valid`와 대응).
- **중국어 줄바꿈 교정.** 앞서 넣은 `text-wrap: balance`가 한자 사이 어디서나 끊어 我家|的快递, 能|不能처럼 어절 내부가 갈렸다. `.font-zh`에 `word-break: keep-all`(구두점 뒤에서만 끊음) + `overflow-wrap: anywhere`(한 절이 한 줄보다 길 때만 글자 단위)를 더하고, 입력칸에서는 balance를 껐다.
- 확인: typecheck 통과, 테스트 51건 통과. 데모 전 구간(MJT 1~5, 핵심 정리, 번역 입력, 피드백 1·2차, 재검토 입력, 완료)의 중국어 줄바꿈을 글자 단위로 실측 — 1500px·1280px 폭 모두 8곳 전부 구두점(，。？) 뒤, 어절 내부 0건.
