# 계정별 학습 데이터 열람 범위

관리자 계정의 학습 데이터 조회 범위를 용도에 따라 구분한다. 전체 명단과 수행 기록은 소유자 계정에서 관리하고, 검토용 계정에는 지정된 예시 계정의 자료만 제공한다. 학습자는 자기 자료를 조회한다.

DB 행 접근 정책과 관련 조회 함수에 같은 범위를 적용한다. 계정과 학습 기록은 변경하거나 삭제하지 않는다. 검토용 계정의 콘텐츠 제작·검토 화면은 유지한다.

검증은 운영 DB의 계정별 조회 결과 및 기존 소유자·학습자 본인 접근 유지 여부에 집중한다. 프런트 배포와 별개로 적용된다.

확인 범위: 지정 예시 자료 조회, 범위 외 자료 조회 제한, 내보내기 권한, 소유자와 학습자 본인의 기존 접근 유지.

운영 권한 변경은 적용되었다. SQL은 이 변경을 재현할 수 있도록 보관했다. 마이그레이션 이력 등록은 별도 실행하지 않았다.
