# 2026-11-01 중→한 시나리오의 저장 전 검토를 Gemini로 교체

- 중→한 뼈대는 GPT-6 Astra가 쓰고 저장 전 의미 검토도 GPT-6 Astra가 하고 있어, 작성 모델과 다른 회사의 모델이 검사한다는 배정 원칙과 맞지 않았다.
- 저장 전 의미 검토 모델을 언어방향으로 나누었다. 한→중 = GPT-6 Astra, 중→한 = Gemini 3.1 Pro. 프롬프트는 같다.
- 작성 전 사전 판정, 뼈대 보정, 미션의 AI 품질 심사는 바꾸지 않았다. R26 산업 적합성 점검(`core_quality_check`)도 그대로다.
- 시나리오 스냅숏 해시 입력의 구조가 바뀌어 `v`를 11로 올렸다.
- 대안: 코드를 유지하고 논문에 예외를 적는 안은 기각했다(연구자 결정).
- 남은 불일치: 한→중에서 Astra가 뼈대를 보정한 경우에는 보정과 검토의 모델이 같다.
