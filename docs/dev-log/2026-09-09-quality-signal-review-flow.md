## 문제와 결정

코어 R9·R30·장면 R16 경고가 품질관리 저장 결과에 없었고, 규칙 경고가 교수자 필수 판단
목록과 SQL 승인 조건에서 빠졌다. Edge는 여전히 미귀속 20% 초과를 실패로 반환했다.

1. 저장 코어의 warning을 미션 경고와 함께 보존하고 TS·SQL 교수자 필수 판단 목록을 일치시킨다.
2. 귀속·HSK·최종 해시를 교수자 판단 전에 한 번 준비하고 R31 구조 실패·R32 경고를 실제 최종 자료로 검사한다.
3. 20%는 교수자 확인 참조값이다. 서버 비율 차단만 제거하고 누락·범위 불일치 등 구조 실패는 유지한다.
4. 승인에서는 준비 자료를 그대로 사용한다. 준비 이후 자료·규칙·검토 해시 교체, 판단 누락·보류·원본 변경을 SQL에서도 차단한다.
5. 새 스냅샷에만 준비 요구를 명시한다. 기존 승인 행을 수정하거나 미션을 일괄 재생성하지 않는다.

warning 표시만 보강하거나 승인 후 귀속을 다시 생성하는 대안은 판단 대상과 승인 대상의
일치를 보장하지 못해 채택하지 않았다. DEC-20260909-02, ITER-20260909-01, EVD-20260909-03.
