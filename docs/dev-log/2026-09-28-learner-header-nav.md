# 2026-09-28 · 학습자 헤더 내비게이션 정리

- 문제: PC 학습자 헤더에서 탭(수업·기록)은 `border-b` 밑줄 때문에 글자가 위로 밀려 옆의 계정 pill과 세로 위치가 어긋났다. 비활성 탭은 옅은 회청색이라 누를 수 있는 메뉴로 읽히기 어려웠고, 계정 버튼만 테두리 pill이라 세 항목의 형태가 달랐다.
- 변경: 세 항목(내 수업·내 기록·내 계정)을 같은 높이(32px)·글자 크기(14px)·아이콘(15px)의 텍스트 메뉴로 통일했다. 비활성 글자를 밝히고 hover 배경을 추가했다. 현재 탭은 아이콘을 노란색으로, 글자 폭에만 노란 밑줄(흐름 밖 absolute)을 그어 표시한다. 구분선을 없애고 세 항목 간격을 같게(4px, 글자 사이 24px) 좁혔다.
- 문구: `수업` → `내 수업`, `기록` → `내 기록`, `계정` → `내 계정`으로 세 이름의 길이·구조를 맞췄다. 정본 용어 「학습 기록」은 기록 페이지 제목(나의 학습 기록)이 유지한다. 모바일 하단 탭 이름도 함께 바뀐다. 계정 드롭다운 내용·로그아웃 동작은 그대로다.
- 검토한 대안: 알약·사각 버튼형 탭은 헤더를 도구 막대처럼 무겁게 만들어 기각했다. `수업 · 학습 기록 · 내 계정`은 세 이름의 구조가 달라 기각했고, `전공 수업`은 대상 범위를 좁히고 페이지 제목(내 수업)과 어긋나 기각했다.
- 검증: 로컬 1280px에서 세 항목의 세로 중심·간격·밑줄 폭을 측정했다. 학습자 컴포넌트 테스트 PASS, typecheck PASS.
- 연구 기록: 학습 설계·계약·데이터 변경이 없는 화면 문구·시각 정리라 `docs/research-trail`은 갱신하지 않는다.
