# 2026-10-06 · 문서 안내와 검토 역할 표기 정리

- README의 문서 안내를 연결된 자료의 성격에 맞게 정리했다.
- 개발 기록에서 연구자와 AI 검토 도구의 역할, 검사 수행 범위, 사용성·콘텐츠 검토 사유를 일관된 문체로 정리했다.
- 기존 검사 결과·수치·검토 의견·결정 및 미확인 범위는 유지했다. 학습설계, 앱 동작, 운영 프롬프트와 데이터 변경은 없다.
- 확인: 문서 diff와 관련 표현을 대조하고 `git diff --check`를 수행했다. 문서 편집에 해당하므로 별도 연구 결정 항목을 신설하지 않았다.
