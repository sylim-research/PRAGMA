## 확인한 사실 (운영 DB 읽기 전용)

- 점검 계정(`d322fda7…`)의 완료 기록은 38건이다. 그중 27건(7/25~7/30)은 `mission_id = sample:request_mitigation_optionality`이고 `speech_act`가 없다.
  이 27건은 프로토타입 시험 기록으로, 현행 미션·화행에 연결할 수 없다. 나머지 11건은 v5 미션에 연결된 정상 기록이다.
- 이 계정에는 v6 수행 기록이 없다. 「통역 8」은 모두 27건 쪽에서 나온 값이다.

- 화면은 이 값이 없으면 화행별 기본 문구를 대신 보여 주고 있었다.

## 바꾼 것 (`src/pages/learner/LearnerRecords.tsx`)

1. **집계 기준을 하나로 정했다(`isCountableLog`).**
   - 기준 = 완료 + 9화행 중 하나 + 미션 id가 시나리오 UUID.
   - 요약 4칸·화행 지도·돌아보기·수정 노트가 모두 이 기준을 쓴다.
   - 제외 건수는 한 줄로 알린다. 원자료는 삭제하지 않았다. v5 기록은 포함한다.
2. **교과목 표기를 집계 범위에 맞췄다.**
   - 제목을 「나의 학습 기록 · 전체 교과목」으로 바꿨다. 조회에는 교과목 필터가 없기 때문이다.
   - 화행 지도와 돌아보기에서 특정 교과목의 주차 번호를 뺐다.
3. **판정성 표현을 뺐다.**
   - 「화용 시그니처」(화행별 고정 유형명)와 「최근 수행의 선택 패턴」(반복 표지 추정)을 지웠다.
   - 대신 「선택한 화행 돌아보기」를 두었다. 완료 건수·최초/최종 표현이 달라진 건수·번역/통역 수만 보여 준다.
   - 「회고 질문 · 모든 학습자에게 같은 질문입니다」를 따로 표시했다.
4. **「수업 확장 연습」 카드를 삭제했다.**
   - 버튼 두 개가 `/scenario` 리다이렉트로 일반 미션 화면에 가고 있었다.
   - 「조건 간 비교 · 상대·매체」는 폐기된 설계(매체 축 2026-07-25, 미션 간 조건 대비 2026-09-17)다.
5. **수정 노트를 고쳤다.**
   - 재검토 지점은 저장값만 사람이 읽는 이름(`SCOPE_LABEL`)으로 보여 주고, 없으면 「미기록」으로 표시한다.
   - 표현이 바뀐 기록이 없으면 노트를 비운다(바뀌지 않은 기록을 대신 보여 주지 않는다).
   - 중국어 말줄임을 없애고 줄바꿈으로 전체를 보여 준다.
6. **색을 정리했다.**
   - 화행 지도를 두 상태로 줄였다. 완료 = 옅은 남색·남색 점, 기록 없음 = 베이지·빈 점.
   - 초록·파랑·회색 신호등 색과 파란 그라데이션을 없앴다.
