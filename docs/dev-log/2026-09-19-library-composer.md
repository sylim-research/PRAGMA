# 2026-09-19 학습 미션 라이브러리·15주 수업 편성 정리

## 학습 미션 라이브러리 (`/admin/library`)
- 편성 가능 = 교수자 최종 승인 기록이 있는 현재본(v5·v6) → 56(v6 11 · 이전 형식 45). 대시보드 「교수자 승인 완료」 58과의 차이 2건 = 옛 콘텐츠 배포판이라 편성 후보가 아닌 승인본.
- 대체된 옛 판: 미편성이면 숨김, 편성돼 있으면 「새 판 있음 · 교체 필요」(8건). 승인 전 = 검수 중인 v6 초안(7, 점검·승인 화면과 일치). 전체 295 = 대시보드 287 + 교체 필요 편성분 8.
- 「이전 형식」 꼬리표·미션 형식 필터, 「승인 기록 없음」 표시(편성된 옛 v5 7건). 목록은 한 줄 표(제목·방향·과제·상태), 10개씩. 이동 버튼·중복 숫자 상자·보조 해설 제거. 입문 열은 비어 있는 그대로 둔다.

## 15주 수업 편성 (`/admin/composer`, 옛 「수업 편성·강의계획서」)
- 1~15주를 한 줄에 한 주씩(두 칸 배치 제거). 미션은 제목 한 줄 + 과제·화용 초점·이전 형식·교체 필요 꼬리표. 새 판이 있는 옛 판은 추가 후보에서 제외.
- 강의계획서 버튼 숨김(교수자 항목이 브라우저에만 저장돼 운영에 쓰기 어렵고 논문에 등장하지 않음). 코드는 유지.
