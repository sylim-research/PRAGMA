# 2026-10-04 DCT 피드백 해설이 인용부의 물음표에서 잘리는 문제

- 관찰: 운영 통역 DCT(요청·한→중)에서 「의미적 충실성 · 수정 권장」 해설이 「…'도와줄 수 있나요?」에서 끊겼다.
- 원인: 화면의 `feedbackSentences`가 `.!?`마다 문장을 나누고 `conciseFeedback`가 앞 두 문장만 보인다. 해설이 원문을 따옴표로 인용하면 인용 안의 `?`가 문장 끝으로 처리됐다. AI 응답과 저장 기록은 온전하고, 화면 표시만 잘렸다(2026-09-10 `acd69275`부터).
- 수정: 따옴표(' " ‘’ “” 「」 『』) 안의 문장부호는 나누지 않는다. 닫히지 않은 따옴표는 뒤를 한 덩어리로 남겨 잘림 대신 길게 보인다.
- 검증: 새 단위 테스트 3건, 학습자 화면 테스트 93 통과, typecheck 통과.
