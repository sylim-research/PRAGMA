## 변경

- 메뉴·화면 제목을 `학급 응답 현황`, 설명을 `저장된 미션 응답을 확인하고, 수업 토론에
  활용할 수 있습니다.`로 바꾸고 메뉴 순서는 유지했다.
- 5명 미만일 때 주차 수업자료로 수업을 진행할 수 있다는 안내와 해당 주차 링크를 제공한다.
- 교수자 화면에 집계 학습자·응답 있는 문항·이견 건수 카드와 문항 선택기를 배치했다.
  선택한 문항의 응답 축별로 큰 막대와 선택 건수·비율을 표시하고, 크게 보기에서도 같은
  선택 상태를 유지한다. 좁은 화면에서는 그래프를 세로로 배치한다.
- 그래프 범위는 항상 0~100%이며 실제 비율에 비례한다. 0건 막대에는 최소 길이를 부여하지
  않는다. 비율의 분모는 각 응답 축의 선택 건수이며 정답 여부를 색으로 표시하지 않는다.
- 새 집계와 count 변환에서 선택지·대상 표현을 미리 자르던 처리를 제거했다. 기존 공개
  스냅샷에 이미 잘린 문구가 저장돼 있으면 이를 소급 갱신하지 않는다.
- DEMO fixture는 변경하지 않았다. `mpj_response_v2`의 scale·band·correction·initial judgment·
  reason·best/worst 응답 필드와 현재 샘플 미션의 선택지를 사용한다. 실제 데이터·DEMO의
  표시 컴포넌트는 같으며 실제 응답이 없을 때 예시로 자동 대체하지 않는다.
- 수집·최신행 집계·마감·공개·최소 인원 로직과 학습자 화면 구성은 유지했다.
