## 판단

중급 한→중 일반·학업, 중급 중→한 실용, 고급 한→중 비즈니스라는 세 과목의 역할 분리는
유지할 가치가 있다. 사용자가 제시한 우선순위는 중급 한→중 번역의 개발 강점 활용,
중→한 학부 수요 대응과 양방향 확보, 제한된 음성 통역 기능의 실제 사용이다.
중→한 수요의 크기는 이번에 별도 조사한 사실이 아니라 사용자 제공 운영 전제다.

다만 한→중 두 과목에 통역 6주를 배정하는 것은 통역을 최소 적용 경로로 운영하려는
현재 개발 전략과 맞는지 재검토해야 한다. 고급·비즈니스·통역 확대를 동시에 핵심 성공 조건으로
두면 검수 부담이 커진다. 고급 과목은 관계·역할·책임·이해관계가 다른 콘텐츠로 구분하고,
새 평가기나 별도 런타임을 만들지 않는 방향을 권고한다.

## 코드·정본에서 확인한 문제

- 현재 6/6 정책은 9·10·11·12·13·14주를 통역으로 분류한다. 핵심 9화행 중 사과·제안·반대·불만이
  통역 구간으로 고정된다. 전반에 배운 같은 화행을 후반 통역에서 모두 다시 수행하는 구조가 아니다.
- 9/3 정책은 12·13·14주를 통역으로 분류한다. 14주는 새 미션 없이 누적 기록을 돌아보는
  메타화용 클리닉이므로 카드의 통역 주차 수와 새 통역 미션 수행 주차 수는 다르다.
- 9개 화행 주차의 미션 18개와 13주 신규 미션 2개를 합치면 과목당 20개, 세 과목 60개가
  기본 콘텐츠 단위다. OT·클리닉·중간·기말의 별도 과제는 이 계산에 포함하지 않는다.
  현행 모드 배정으로 이 60개 중 24개가 통역이다. 이는 계획상 계산이며 실제 완성 콘텐츠 수가 아니다.
- 학습자 정본 §4.1에는 비즈니스 10/2·중한 번역 12주가 남아 있고, 코드·운영 화면은
  비즈니스 6/6·중한 9/3이다. 어느 수치를 자동으로 정답으로 삼지 않고 사용자 결정 후 정합화한다.

## 권고 방향과 경계

세 과목·수준·언어방향·9화행·MJT5+DCT1·15주 골격을 유지하되, 첫 두 과목은 번역을 중심에
두고 통역은 실제 검증 가능한 적용 범위로 제한한다. 고급 과목도 비즈니스 화용 판단의 심화를
우선하며 통역 비중을 높이는 것을 고급의 정의로 삼지 않는다. 6/6을 일괄 9/3으로 바꾸는 것보다
실제 미션 수행과 특별 주차를 구분해 목표·모드·콘텐츠·검증을 먼저 대조한다.

통역은 현재 원발화 청취→녹음→전사 확인→피드백·수정 경로이며, 확정 전사가 저장된다.
음성 유창성·발음·실시간 통역 수행을 종합 평가하는 도구로 확대 해석하지 않는다.
참고한 유럽위원회 SCICtrain도 통역 교육을 speechmaking·정보 우선순위·수행 평가 등으로 구분한다.
이는 PRAGMA의 특정 주차 비율을 정당화하는 근거가 아니다.

검토만 수행해 테스트를 재실행하지 않았다. 새 설계가 채택되지 않아 research-trail의
decision·traceability를 수정하지 않았다. 채택 시 교과목 정본과 실제 편성을 함께 갱신해야 한다.

## 2026-09-06 추가 점검 — 교강사 주차 계획의 유연성

- 단독 진행 적합: 읽기 전용 기능 조사와 로컬 순수 검증 함수 실행. 운영 저장·편성 변경 없음.

  기존 미션 배정과 변경 계획이 충돌하면 저장 전에 교체·제거를 요구한다.

  주를 건너뛴다. 이는 주차별 복수 목표 화행을 명시하는 완성된 편집 기능과 구분한다.

  미션 수는 경고였다. 운영 DB 저장이나 브라우저 종단 테스트를 수행한 결과는 아니다.
- 완전한 유연성에는 미달한다. 자동 편성은 정규 화행 주차당 `slots = 2`를 사용하고,

  다른 두 화행을 골라 번역 1건·통역 1건의 독립 미션으로 편성하는 것을 제안한다.
- 7·14주는 기존 로그의 최초 선택·피드백·수정 근거를 검토하는 실제 수업 활동이다.
  새 Full Mission 필수량에는 포함하지 않는다. 과목당 9×2+2=20건(번역 10·통역 10),
  세 과목 60건(번역 30·통역 30)이 계획상 신규 미션 요구량이다. 확보·검수 완료 수가 아니다.
- 카드 표기는 `12주 학습 · 주차별 번역·통역 병행`과 상세의 `화행 학습 9주·새 맥락 적용
  1주·피드백 회고 2주`를 제안한다. 번역·통역 주차를 서로 배타적인 수로 표시하지 않는다.
- 전략 판단: 중급 한중은 기존 강점을 활용하는 핵심 경로, 중급 중한은 사용자 제공 학부 수요와
  양방향 지원의 경로, 고급 한중은 이미 강점이 있는 방향에서 업무 맥락을 심화하는 경로로 둔다.
  세 과목의 차별화에 별도 러너·평가기나 새 화행을 요구하지 않는다.
- 실행 순서는 중급 한중 요청 주차의 번역·통역 두 건을 검수·편성·수행·기록까지 확인한 뒤,
  중급 중한과 고급 한중 요청 주차까지 총 6건으로 적용 범위를 확인하고 나머지 주차를 채우는
  안을 제안한다. 현행 동일 모드 제약의 변경과 실제 음성 서비스 확인이 필요하다.
- 세 과목은 추천 프리셋으로 관리하는 방향을 제안한다. 주차 안의 번역·통역 혼합을 위해
  바꾸는 미션별 편성 규칙에 또 다른 전역 고정을 추가하지 않는다. 완전한 자유 강좌 편집은
  세 과목 완성 작업과 별도 범위로 두며 이번 제안에 포함해 구현하지 않았다.
- 외부 참고: Council of Europe의 `Mediation in the classroom`은 언어·문화적 장벽을 넘어
  의미를 전달하고 의사소통을 가능하게 하는 활동을 설명한다. 이는 맥락 중심 목표 설정의
  참고이며, 위 12주 비율이나 학습 효과를 입증하는 근거로 사용하지 않는다.
  https://www.coe.int/en/web/common-european-framework-reference-languages/mediation-in-the-classroom

새 테스트를 실행하지 않았다. 확정된 설계 변경이 없어 research-trail과 세 정본은 유지했다.

## 2026-09-06 추가 검토 — 고정 주수 폐지와 번역·통역·통번역 유형

상태: 사용자가 고정 주수 배분을 없애는 운영안의 **검토**를 요청했다. 아래는 미채택 제안이다.
이번 코드 변경은 수준 배지 톤 조정뿐이며, 6/6·9/3 주수나 실제 편성·DB를 바꾸지 않았다.

### 권장 운영안

교과목의 수준·방향·주제와 수행 유형을 별도 축으로 둔다. 현재 세 과목을 각각 번역·통역·통번역으로
하나씩 배정할 필요는 없다. 현재 세 과목의 수준·주제 구성을 유지하면서 모두 통번역형으로 운영할 수 있다.

| 교과목 유형 | 정규 화행 주차의 수행 | 주수 설정 |
|---|---|---|
| 번역 | 해당 화행의 완결된 번역 미션 2개 | 번역/통역 주수 비율을 설정하지 않음 |
| 통역 | 해당 화행의 완결된 통역 미션 2개 | 번역/통역 주수 비율을 설정하지 않음 |
| 통번역 | 해당 화행의 번역 미션 1개 + 통역 미션 1개 | 같은 화행 주차 안에서 양쪽을 수행 |

- 세 유형 모두 공통 9화행·두 글자 명칭·수준·방향·주제 및 유연한 중심 질문을 유지하는 제안이다.
- 예를 들어 요청 주차의 통번역형은 요청 번역 1개와 요청 통역 1개, 감사 주차도 감사 번역 1개와
  감사 통역 1개다. 각 미션은 MJT5+DCT1의 독립적인 완결 활동이다. 화면 또는 산출 방식만 바꾸지 않는다.
- 번역의 발신자 관점과 통역의 A–통역사 C–B 역할은 다르므로 각 미션의 상황·원문·P/D/R을 별도로
  설계·검수한다. 주차의 중심 질문으로 두 상황을 동일하게 강제하거나 점수를 곧바로 동등 비교하지 않는다.
- 13주는 교수자가 선택한 기존 화행을 새로운 두 상황에서 보완한다. 통번역형을 채택하면 두 상황을
  번역·통역 하나씩 설계하는 제안이다. 7·14주 클리닉, 1·8·15주 운영을 새 미션 주차로 바꾸지 않는다.
- 목록에는 실제 유형만 간결하게 표시하고, 주차 화면에서 해당 활동을 명시한다. 준비되지 않은
  통역 미션을 번역 미션으로 조용히 대체한 뒤 통번역 운영이 완성됐다고 표시하지 않는다.

### 대안과 판단

| 안 | 장점 | 남는 제약·비용 | 판단 |
|---|---|---|---|
| 목록만 세 유형으로 표시 | 표시 변경이 작고 기존 편성을 유지 | 실제 6/6·9/3 배분은 그대로 | 고정 주수 폐지의 해결책은 아님 |
| 통번역형에서 교수자가 주차별 번역/통역 선택 | 상황·수업에 맞춰 선택, 같은 모드의 두 미션 규칙 유지 가능 | 일부 화행을 한 모드로만 수행, 명시적인 주차 모드 저장·검증 필요 | 자유 배치를 우선한다면 대안 |
| 통번역형에서 화행마다 번역 1개·통역 1개 | 각 화행을 양쪽 수행으로 다루고 주수 할당 제거 | 동일 모드의 두 미션 계약과 편성·자료·노출 규칙 변경 필요 | 화행 중심 통번역 수업에는 이 안 권장 |

권장 이유는 화행별 양쪽 수행 기회를 일관되게 제공한다는 운영상의 장점이다. 학습 효과나 최적 비율이
입증됐다는 주장이 아니다. 앞서 검토한 주차별 선택안보다 구현 범위는 크지만, 화행마다 번역·통역을
함께 다루려는 목적에는 더 직접적이다. 번역·통역 전용 강좌도 포함하는 세 유형 전체를 매번 새로 만들거나,
세 교과목을 아홉 개로 복제하는 확장은 제안하지 않는다.

### 채택 시 필요한 실제 구현 범위

1. 강좌 유형에서 미션 슬롯별 기대 모드를 결정하도록 편성 정책을 바꾼다. 자동·수동 후보 필터와
   저장 검증을 함께 수정해야 한다. 기존 주수 계산 함수를 지우는 것만으로 끝나지 않는다.
2. 동일 모드 A/B 맥락 대비 계약을 통번역형의 두 독립 활동에도 그대로 적용하지 않는다.
   같은 화행·수준·방향과 완결 미션 2개는 유지하되, 모드·역할 차이를 허용하는 편성 계약을 명시한다.
3. 학습자 노출, 강의계획서·수업자료·HOOK의 모드 참조, 콘텐츠 검수와 승인 스냅샷을 동기화한다.
4. 기존 주수 컬럼·DB 제약과 편성의 전환 방식을 정하고, 기존 승인·수행 기록을 소급 변환하지 않는다.
   실제 필요한 번역·통역 콘텐츠의 검수 완료 여부를 확인한 후 편성한다.
5. 한 화행 주차의 번역·통역 두 미션으로 생성/검수·편성·학습·기록 연결을 확인하고, 세 과목의
   방향·수준에 적용한다. 설계 채택 후 정본·연구 기록을 갱신한다. 현재는 이 검증을 완료하지 않았다.
