# 2026-09-16 · v6 학습자 미션 안내 화면 복구

## 확인한 불일치
- DEC-20260915-01은 「v6 도입은 흐름을 안내한다」로 정했다.
- 그러나 학습자 실행 화면은 `mission_v6`를 도입 없이 MJT1부터 시작했다. 교수자 검토 미리보기에만 도입이 보였다.
- 교수자 체험 검토(대표 v6 2번) 중 「미션 안내가 허전하다」는 메모에서 드러났다.

## 수정
- v6 학습자도 시작 전에 안내 화면 1장을 본다. 관리자 미리보기와 같은 컴포넌트다.
- 활동 6개 카드를 보여 준다: 상황에 맞는지 판단 / 판단하고 이유 고르기 / 고친 표현 고르기 / 직접 고치고 비교하기 / 여러 표현 비교하기 / 새 상황 직접 번역·통역.
  - 핵심 정리는 독립 과제가 아니므로 6번 카드 문장에 포함했다.
- 문항 내용·정답·DCT 장면은 안내에 보이지 않는다.
- 진행 막대에 v6도 「미션 안내」 단계가 붙는다(v5와 같은 모양).
- 개발용 로컬 파일럿은 기존대로 도입 없이 시작한다.

## 바꾸지 않은 것
- 문항 구조·수량, DCT 흐름, 저장 응답, 완료 조건, v5 도입, DB.
- 이 수정은 설계 lock(DEC-20260915-02)의 허용 조건인 「현행 설계와 구현의 명백한 불일치」에 해당한다.

## 캡처
- 제4장 학습자 미션 흐름의 overview 도판 후보다: 미션 시작 직전 상태, PC 화면 전체 1장.
- E2E 전에 배포해 E2E 캡처와 같은 기준본을 쓴다.

## 검증
- `npm run typecheck`, 학습자·검토 미리보기 테스트 12파일 75건, `npm run build` 통과.
- 운영 화면 확인은 배포 후 관리자 검토 미리보기에서 한다.
