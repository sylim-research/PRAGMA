# 대표 데모 답안 채워넣기

- 문제: 실제 수업 설명 중 답안을 직접 입력·선택하지 못해 다음 단계로 넘어가지 못했다.
- 범위: 사용자 요청한 대표 데모 /demo/mission의 시연 보조만 추가. [단독 진행 적합].
- 기준: 최신 origin/main a02172d5, clean 보존 worktree의 codex/demo-answer-fill-2026-09-08.
- UI 브리프: 데모 상단에 “데모 답안 채워넣기” 버튼을 두고 현재 문항만 채운다. 기존 확인·제출 버튼으로 진행한다. 장면 소개·산출 전 정리·완료·과거 응답 보기에는 표시하지 않는다.
- 사용자가 앞서 승인한 커밋·푸시·배포 절차를 이어 적용한다. 최종 main·CI·Railway·운영 확인은 이 변경 PR의 배포 확인 절에 기록한다.

## 변경

- CanonicalMissionRun: 현재 문항의 기존 참고 선택을 채운다. 직접 산출에는 그 미션에 저장된 참고안을 사용하며 개발용 고정 문장을 가져오지 않는다.
- 피드백 단계: 첫 제출문과 다른 저장된 참고 표현이 있으면 수정 입력란에 채운다. 같은 화면을 유지하므로 다시 채워도 AI 피드백을 재호출하지 않는다. 예시는 실제 피드백 문제를 자동 해결했다는 판정이 아니다.
- InterpretingConsole: 데모 전사 예시를 채운 경우 실제 녹음이 아님을 표시하며 녹음·TTS·STT를 자동 호출하지 않는다. 전사 확인·제출은 기존 버튼으로 한다.
- 기존 학습 화면에는 새 버튼을 노출하지 않는다. 답안 검사·제출 조건·미션 진행 순서·AI 평가·기록 스키마·저장 콘텐츠는 변경하지 않았다. 데모의 수행 로그·이벤트 미저장 조건을 유지한다.
- 답안 채우기만으로 자동 제출하거나 앞서 제출한 응답을 덮어쓰지 않는다. 재시작하면 빈 첫 문항으로 돌아간다.

## 검증

- npm.cmd run typecheck 통과.
- 관련 4파일 22 tests 통과: CanonicalMissionRun.runtime / connections / reason, InterpretingConsole.
- 새 번역·통역 데모 회귀 2건: 실제 런너의 장면 소개 → 다섯 판단 문항 → 직접 산출 → 피드백 → 수정 → 완료·재시작을 버튼으로 진행. 반복 채우기 뒤에도 피드백 요청 1회, 학습 로그·이벤트 저장 0회를 확인했다. 테스트 피드백 호출은 mock이다.
- 로컬 실제 대표 미션: 다섯 문항에서 채우기·확인·다음 단계 진행 성공. DCT 입력란에 저장된 중국어 참고안이 채워지고 “번역 제출하기” 활성화 확인. 상단 버튼 배치 스크린샷 확인. 실제 AI 요청은 실행하지 않았다.
- 기존 일반 통역 녹음·전사 확인·제출 회귀 2건도 통과했다.
- 운영 배포 전 전체 테스트·production build는 필수 PR CI에서 확인한다.
