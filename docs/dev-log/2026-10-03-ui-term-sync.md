# 2026-10-03 화면 문구 용어 정합 (공개·학습자 화면)

배포본(`pragma.up.railway.app`, `0477084f`)의 공개 화면, 대표 미션 시연 전 과정, 학습자 교과목·주차·미션 안내·내 기록을 논문 용어 기준과 대조해 발견한 문구만 고쳤다. 관리자 화면은 아직 점검 전이다.

## 바뀐 것

- **DCT 상태명**: 화면의 「최종안」 → 「확정안」(미션 안내 「확정안을 내가 결정하기」, 안내문, 재검토 제목·입력란 이름, 완료 문구). 재검토의 확정 버튼은 「이 번역(통역)으로 확정하기」로 통일. 데모 기록의 「최초안·최종안」 → 화면 이름 「최초 번역·최종 번역」. 「내 판단으로 최초안을 확정」 → 「초안을 그대로 확정」.
- **세 검토 기준**: AI 피드백 칸 「의미 충실성·문법 정확성」 → 「의미적 충실성·문법적 정확성」.
- **관계·상황 조건 표시**(`CanonicalMissionRun` 안내): 「상대적 지위·친숙도·부담」 → 「상대적 권력·사회적 거리·행위 부담도」.
- **MJT 결과**: 「맞았습니다」 → 「기준 판단과 같습니다」. 판단과 이유 문항의 「가능한 수정 예시」 → 「참고 표현」.
- **전체 구조**(`/architecture`): 「PRAGMA · 통합 워크플로우」 → 「PRAGMA 워크플로우」, 「DCT형 통번역 산출」 → 「DCT형 통번역 과제」, MJT 활동명을 화면 표시명(단일 표현 판단·판단과 이유·복수 표현 비교·수정안 선택·직접 수정)으로, 「의미·언어·화용 3층」 → 「의미·문법·화용 기준」, 「이견 제기」 → 「학습자 의견」, 「최초안·최종 산출」 → 「초안·확정안」, 「관문」 → 「승인 단계/승인된 미션」, 「승인 미션」 → 「승인된 미션」, 「교수자 검토」 → 「교수자 감수」, 「연구 데이터」 → 「연구 자료」.
- **그 밖**: 첫 화면·내 기록 「화행 목적」 → 「화행목적」, 주차 화면 「학습목표 · …상황과 상대에 맞게」 → 「학습 목표 · …관계와 상황에 맞게」(요청 주차 기본 문구), 주차 수업자료 「교수자 검수 후 공개」 → 「교수자 최종 승인 후 공개」, 교과목 카드 보조 라벨 「수행모드」 → 「수행 방식」, 개인정보처리방침의 「판단 과제 응답·이의·검수·연구윤리」 → 「MJT 응답·학습자 의견·AI 검토·연구 윤리」.

## 바뀌지 않은 것

- 학습 흐름, 판정 로직, 저장 구조, DB 데이터. 내부 식별자·주석.
- DB에 저장된 문자열(미션 제목 「번역 학습 미션」, 학습자 의견 안의 내부 꼬리표)은 데이터라 손대지 않았다.
- 복수 표현 비교의 「허용 판단」 꼬리표 표시 방식은 의미 판단이 필요해 보류했다.
