## 검토 경과

- 1차: 분포판을 주차 운영 화면 안에 펼침 → 여전히 클릭해야 보이고 편성 화면과 겹친다는 지적.
- 2차: 「학급 응답 분포」 독립 메뉴 + 흐린 예시 분포 → GPT 교차검토: 예시 숫자(12명·42%)가 캡처 한 장에서 실제 결과처럼 읽힌다. 운영 화면에서 mock 제거로 합의.
