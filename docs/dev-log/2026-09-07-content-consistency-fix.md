# 기존 콘텐츠 정합성 오류 수정 · 2026-09-07

## 범위와 원인

- [독립 검토 권고] 생성·검수 기준 보완이다. 사용자 요청에 따라 기존 모델·MJT5+DCT1 설계를
  유지하며 국소 수정과 실제 실패 사례 검증을 진행했다. 운영 콘텐츠 소급 수정·LOCK은 하지 않았다.
- 요청·거절 파일럿의 원시 응답을 대조했다. 요청의 P 반전과 이유 선택지의 동의적 반복은
  모델 원문에서 발생했다. 거절의 상사 관계/P 오류에 더해 서버가 Anchor PDR을 코어 값으로
  덮어쓰고 대비 축을 임의 보정하여, 다른 관계의 장면을 맞는 코드처럼 통과시키는 문제가 있었다.
- 후보 재생성 뒤에는 후보 국소 검사만 수행하여, 그대로 남은 문항 해설과 새 후보의 모순을
  놓칠 수 있었다. 다음 critic 입력에 이전 quality_check·provenance가 포함되어 오래된 인용을
  따라가는 현상도 실제 호출에서 관찰했다. 모든 오류를 모델 또는 후처리 하나의 원인으로 단정하지 않는다.

## 변경

- 장면 생성 응답 형식에서 Anchor는 코어 PDR로 고정하고 X/Y는 정확히 한 축만 다른 6개
  조합 중 선택하도록 제한한다. 모드별 채널도 제한한다. 반환한 PDR을 덮어쓰지 않고 검증한다.
- 실패한 장면을 1회 재시도 입력에 함께 제공한다. X/A/Y/C는 PDR만 공유할 수 있고 서로
  다른 구체적 사건이어야 함을 명시한다. 기존 두 번 시도 제한과 실패 차단은 유지한다.
- 모든 화행·방향·모드에 화자 기준 P의 정의, 상대 중심 관계 서술, 이유 오답의 서로 다른
  오진 원칙을 적용한다. R4는 공백·문장부호 차이뿐인 동일 이유 선택지를 차단한다.
- 기존 두 번째 critic 호출을 장면·이유·해설·의미 보존 네 영역으로 구성한다. 네 영역 응답을
  필수로 받고, 검사 미완료를 정상 통과로 처리하지 않는다. 이전 판정·수리 이력은 입력에서 제외한다.
- 후보 재생성 후 수정본 전체 품질점검을 실행한다. 새로 발견한 해설 모순과 이전 비대상 fail을
  함께 보존한다. 실패 revision은 기존 격리·승격 차단 규칙을 따른다.
- 모델 변경 없음: 미션 gpt-4o, critic gpt-4.1. 일반 품질점검 호출 수는 기존 두 번이며,
  후보 재생성이 발생한 경우에만 전체 재검수가 추가된다.

## 확인

- 집중 회귀 테스트 38개·typecheck·운영 build 통과. PR CI·배포 결과는 아래 배포 기록에 남긴다.
- 실제 모델 최종 확인: 기존 요청 초안의 P 반전·이유 중복, 거절 초안의 자기모순 관계·이유
  중복을 grounded fail로 검출했다. 요청·거절·사과 장면 구성은 보완 과정에서 각각
  bounded topology 검사를 통과했다. 이것은 완전한 새 미션 세 건의 품질 통과가 아니다.
- 정합성 critic에도 거절 MJT5의 이웃 장면을 상사 장면으로 읽은 오탐이 1건 있었다.
  현재 경로에 없는 인용은 기존 grounding 검사가 격리했다. 실제 값 인용만으로 의미적 정확성을
  보장할 수 없으므로 교수자 검수·확정 절차를 유지한다.
- 검증은 기존 파일럿의 로컬 초안을 사용했다. 운영 시나리오·편성·학생 수행 기록은 변경하지 않았다.
  관리자 인증과 만료 토큰을 요구하는 임시 검증 함수는 확인 후 삭제했다.
