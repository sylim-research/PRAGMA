# 2026-09-19 MJT2 결과 공개 시점 변경

- **변경**: MJT2(적절성 판단 + 이유) 흐름을 `판단 확정 → 이유 선택·확정 → 판단과 이유의 결과·해설 공개`로 바꿨다.
  2026-09-18 흐름(`판단 확인 → 판정 O/X → 이유 선택 → 이유 O/X`, `2026-09-18-mjt-verdict-ui.md`)을 대체한다.
- **판단 확정 직후**: 네 선택지와 내 선택(선택 윤곽)은 그대로 두고 변경만 잠근다. 「내 선택 ✓/✕」·「기준 판단」·「인정 범위」 배지,
  정오 색상, 스크린리더 판정 문장은 나오지 않는다. 스크린리더에는 「판단을 확정했습니다. 내 선택 ○○. 이제 가장 큰 이유를 …」만 알린다.
- **이유 확정 후**: 판단 배지·색상·판정 문장과 이유 정오·해설이 함께 공개된다.
- **버튼 문구**: 「판단 확인하기」→「판단 확정하기」, 「이유 확인하기」→「이유 확정하기」(MJT2만). 다른 문항(MJT1·3·5, 이전 형식)의 문구와 동작은 그대로다.
- **데이터**: 응답 형식 `{ pick, reasonId }`와 직렬화(`buildMissionV6Responses`)는 바꾸지 않았다.
- **코드**: `src/pages/learner/CanonicalMissionRun.tsx` `ScaleView`(잠금 `judgmentLocked`와 공개 `judgmentShown` 분리).
  교수자 미리보기(`InstructorReviewExperience`)도 같은 컴포넌트라 같은 흐름이다.
- **검증**: `npm run typecheck`, 전체 테스트 1028개 통과, `npm run build` 통과, localhost 전후 화면(Playwright) 확인.
- **확인 필요**: 이 변경은 학습자에게 결과가 보이는 시점을 바꾼다. research-trail(02 결정) 기록과 원고 MJT2 서술 대조는 아직 하지 않았다.
