- `/admin/package`의 기존 주차 화면에 생성 패널을 추가했다. 별도 메뉴·범용 노트북 앱은 만들지 않았다.
- 신규 `teaching-materials` Edge 하나가 `lesson`과 `discussion`을 처리한다.
  일반 10주(2~6·9~13)는 그 주차의 완전한 승인 미션 두 개, 7·14주는 각각 2~6·2~13주의
  같은 교과목 승인 미션 최대 여섯 개를 선택한다. 방향·수준·공개 버전·수행모드 조건을 재사용한다.
- 교수자가 추가할 수 있는 원자료는 확인한 본문과 출처다. 본문 12,000자·출처 500자 및
  시스템·사용자 프롬프트 합계 100,000자 한도를 검사한다. 원자료를 조용히 절단하지 않는다.
- `근거 선택 → 프롬프트·입력 확인 → 명시적 생성 → 초안 저장 → 수정 → 기존 콘텐츠 검토·승인`.
  확인 요청은 유료 모델을 호출하지 않는다. 생성은 기존 mission 모델 경로의 기본 `gpt-4o`를 사용한다.
  `weekly_teaching_v1` strict JSON schema와 로컬 검증기를 공유하고, 거절·잘림·잘못된 구성은 저장하지 않는다.
  모델 자동 대체·재시도·자동 승인은 없다.
- `weekly_teaching_materials`는 관리자만 읽는 버전별 초안 저장소다. 쓰기는 관리자 인증을 마친
  서버의 service RPC로만 하고 과거 버전은 덮어쓰지 않는다. 모델 요청·응답 ID·모델·입력 지문·근거를 보존한다.
  호출 전 확인 지문, 저장 시 최신 근거와 예상 revision을 다시 대조한다.
- 새 revision·편성·선택 근거 변경은 이전 주차 승인을 무효화한다. 기존 주차 검수 원본·승인 경로에
  생성 자료를 연결하고, 이전 주차를 토론 근거로 쓸 때도 현재 미션 승인 여부를 확인한다.
  새 자료가 없는 주차의 기존 source hash·승인 이력은 보존한다.
- 공용 네 절과 교수자 진행 메모를 분리한다. 승인 유인물·프로젝터·HTML에는 공용 필드만 투영한다.
  원자료 전문·모델 요청·교수자 메모는 학생에게 반환하지 않는다. 생성 본문의 의미 적합성은 교수자 검토 대상이다.
- 개인 응답이나 집계를 모델에 전달하지 않는다. 토론 중 학습자가 기존 수행 기록을 참고할 수 있고,
  기록이 없어도 준비된 사례로 참여하도록 지시한다. 새 학습자 활동 저장·채점 기능은 만들지 않았다.
- 저장된 근거 선택을 다시 열 때 복원하고, 편성에서 빠진 미션은 재생성 선택에서 제거한다.
  긴 출처 주소는 유인물·HTML에서 줄바꿈한다.
