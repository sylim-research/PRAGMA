# 2026-09-18 교수자 최종 승인 화면 정리

- 문제: 승인 화면에 자동 단계를 돌리는 버튼(「감수 자료 준비」·「추가 모델 검토 선택」·「최종 검수 자료 실행 · 유료」)과 내부 표현(「저장된 OpenAI 검토 재사용 · 추가 호출 없음」)이 그대로 보였다. 교수자는 무엇을 하는 버튼인지, 왜 승인 단계에 있는지 알 수 없다고 했다. 근거 확인에 실패해 격리된 AI 지적(「현재 표현 인용이 없습니다」)도 본문에 보였다.
- 원인: 등록 경로가 규칙 검사·근거 기록(최종 검수 자료)을 끝내지 않고 승인 화면으로 넘겼다. 화면은 파이프라인 운영 콘솔과 최종 판단 화면을 같은 부품으로 그렸다.
- 조치(화면): `ContentReviewPanel`의 승인 화면 모드(`experiential`)에서만 — 자동 점검이 덜 끝난 버전일 때만 안내 한 줄과 「자동 점검 마치기」 버튼 하나 · 추가 모델 검토 선택과 단계 실행 버튼 숨김 · 섹션 제목 「자동 점검 결과」(+「자동 점검 완료」) · AI 검토 제목 「AI 검토」 · 격리된 근거 실패 지적은 「자동 점검 내역」 접힘으로. 품질 점검 화면(`/admin/ai-review`)은 그대로. 서버·DB 변경 없음.
- 조치(운영): 칭찬 배치 5건은 인계 스크립트(`prepareContentReview`와 같은 경로)로 규칙 검사·근거 기록을 미리 끝냈다. 1건은 이미 승인돼 있었다.
- 검증: `npm run typecheck` 통과, 관리자 테스트 16파일 114건 통과(승인 화면 테스트 2건 추가), localhost에서 관리자 로그인 후 두 미션(`5f061550`·`a96f147d`)으로 확인 — 실행 버튼·유료 표시·추가 모델 선택 없음, 「자동 점검 결과 · 자동 점검 완료」, 「AI 검토」, 격리 지적은 내역에만.
- 남은 것: 근거 기록 단계가 교수자 쟁점 판단을 초기화하는 서버 동작(현재 화면 경로로는 도달 불가, P1 · Edge 배포 필요).
